# 阅读说明与术语表（先看这一页）

> 这份报告里出现了不少"内部代码词"。这一页用大白话把它们讲清楚；正文第一次出现这些词时，都以此处定义为准。

## 一、数据是怎么组织的

| 词 | 大白话 |
|---|---|
| **语料** | 从 BWiki 抓下来的游戏剧情文本，一共 26,332 条（约 56.7 万字） |
| **一条记录** | 一句台词、一句旁白、或一个玩家选项，是统计的最小单位 |
| **步骤（step）** | 一段连续剧情（比如"和某人对话""进入某地"），共 723 个；统计时把同一步里的句子算作一组 |
| **版本** | 剧情章节 3.0–3.7，共 8 个 |
| **任务页** | BWiki 上的一个剧情页（67 个），一个任务页包含多个步骤 |
| **主线 / 支线** | 本报告只用主线（开拓任务），不含活动与角色故事 |

## 二、剧情里的关键概念（本报告的核心对象）

| 词 | 大白话 |
|---|---|
| **神谕** | 剧情里"命中注定"的那句预言，全篇 13 条，每条对应一位黄金裔 |
| **吟诵段** | 角色**原样念出**神谕的那一段 |
| **兑现段** | 神谕**在剧情里实现**的那一段（可能和吟诵段是同一段！） |
| **字面兑现** | 神谕说什么、剧情就照做什么（如"背后负创而死"） |
| **反转兑现** | 剧情把神谕**读反**了（如"相拥=永恒离别"被改成"拥抱=爱"） |
| **错位兑现** | 神谕实现了，但**换了对象/地点**（如"征服群星"被换成"改写律法"） |
| **追认** | 事件**先发生**，之后才被说成"这就是神谕"（时间方向反了） |
| **黄金裔** | 游戏里的"半神候选人"，本报告按 **11 位**计 |
| **单列角色** | 开拓者、三月七、丹恒——重要，但不是黄金裔，单独分析、不跟黄金裔比较 |
| **NPC 注记** | 荒笛、玻吕茜亚——只在相关角色条目里提一句，不单独成组 |
| **刀子场景** | 玩家社区说的"高光/虐心剧情"，本报告收了 36 个 |
| **关键事件** | 报告里选出的 30 个剧情节点，每个都写了"之前什么意思 → 之后变成什么意思" |

## 三、统计与模型词

| 词 | 大白话 |
|---|---|
| **检测器 A** | 一个"自动打分"程序：**只看词面与情绪词**，给每个步骤打一个"显著度"分数 |
| **检测器 B1** | 另一个打分程序：在 A 的基础上**加上叙事结构特征**（转折、呼应、重复），一般认为更靠谱 |
| **检测器 B2** | B1 的"短步骤修复版"，试验后效果更差，**已弃用**，报告只在"失败案例"里提到 |
| **Top100** | 把 686 个步骤按检测器分数从高到低排，取**前 100 名**；"Top100 命中 13/35"=36 个刀子里有 13 个进了前 100 |
| **排名 / 中位数** | 某个步骤在 686 个步骤里排第几；中位数就是"一半比它高、一半比它低" |
| **人工标注** | 人工（或 LLM 辅助）给步骤打的"显著度 0–3 级"标签，74 条 |
| **κ（kappa）** | 衡量两个人/两次标注**一致性**的指标：越接近 1 越一致；本报告二次加权 κ=0.788（"较好"水平） |
| **TF-IDF** | 一种**按词加权**的文本向量：一个词在本段常见、在全局少见，就更重要。它的前提是"词袋"（只看词出现没有、不看词序），所以只看"字面像不像" |
| **词袋** | TF-IDF 的建模前提：把文本当成一袋词，不管词序。只在解释 TF-IDF 时用这个词，它不是第三种方法 |
| **句向量** | 一种**按语义**把句子变成数字向量的表示（本文用 bge-small-zh-v1.5 生成，512 维；文中统一叫"句向量"）；"字面不同但意思像"也能算相似 |
| **SBERT / bge** | 生成句向量的具体模型名，只在本文首次说明时出现；正文不再把它当方法名 |
| **余弦相似度** | 两个向量"方向"有多接近，取值 −1 到 1；本报告用它衡量"像不像"，**不是"含义强度"** |
| **质心（角色向量）** | 把某角色所有台词向量平均，得到一个"角色总体向量"；用于"整段文本像不像这个角色" |
| **LSA / BM25** | 另外两种文本检索方法：LSA 是降维后的词向量，BM25 是经典的词频检索公式 |
| **MRR** | 检索指标：正确结果排第 1 得 1 分、排第 2 得 1/2、排第 k 得 1/k，再平均；**越高越好，0 表示完全没找到** |
| **Recall@k** | 前 k 个结果里找到正确结果的比例；本报告的 k 多为 5/10/20 |
| **L3 精读** | 让模型把某角色全部台词**逐条读完**（带上下文），写一份"分版本弧线 + 发现"的笔记；共 14 份 |
| **覆盖率** | 某个角色的台词/步骤里，被"刀子/关键事件/标注"覆盖到的比例；覆盖率低≠没分析，只是没被重点标注 |

## 四、报告里几个容易误解的说法

| 说法 | 含义 |
|---|---|
| **"显著"** | 指**人工标注的显著度**（0–3 级），不是统计学的"显著" |
| **"语言突变"** | 检测器分数高的步骤，语言上与前文差异大；**不等于"剧情最虐"** |
| **"与神谕相似度为 0.61"** | 只是**向量接近程度**；相似度高不代表角色在谈论命运，也不代表写得好 |
| **"逆序/时间倒置"** | 文本里的顺序（按任务页）与故事时间不一致，比如 3.5 里有大量回放/另一条时间线 |
| **"十一位黄金裔"** | 游戏说"十二"，但"岁月"这个位置换过很多人，实际固定 11 位；报告口径按 11 位，并在第 6 章用文本名单（#26119–#26122 vs #26176）证明"十三英雄 = 11 黄金裔 + 三月七 + 丹恒" |

## 五、每个数字怎么回原文

图 → `data/plot_data/` 里同名 CSV（这张图画的数据）→ 配置/矩阵 → `record_id`（台词编号）→ `data/corpus/amphoreus.final.jsonl` 原文。任何结论都可以沿这条路核对。
