# 第 3 章 命定如何被角色接管

> 本章回答第二个问题：**神谕如何从"外部命运"变成"角色自己的语言"？** 结论先行：接管不是改写文本，而是**引用的主体从旁白/他人转向本人、并在结局以宣告完成**；34 处引用的阶段分布与"谁替谁念"的个案支持这一点。但这是**弱趋势**，13 条神谕里只有 8 条真正走完了弧线。

## 3.1 34 处引用在做什么

把每一处引用按话语角色编码（`data/config/oracle-citation-coding.json`，编码规则见 `data/reports/oracle-citation-timeline.md`）：

| 阶段 | 条数 | 例 |
|---|---|---|
| 结局宣告 | **8** | 白厄「诚如神谕所示……愿这名号能代我同行」（#16719） |
| 他人解释 | 7 | 阿格莱雅替赛飞儿念「汝将与贪婪同行」（#10237） |
| 原文出现 | 6 | 阿格莱雅自述「汝将最后一次沐浴……」（#7458） |
| 本人引用 | 5 | 赛飞儿「那愚蠢的预言也有我一份」（#11907） |
| 旁白转述 | 4 | 「白厄在麦田中梦见一道神谕」（#15680） |
| 改写反转 | 3 | 白厄把「碎作千片」改写为给自己的话（#17080） |
| 主动认领 | 1 | 遐蝶「还记得那句预言吗」（#11467） |

引用者身份：**本人 19、他人 10、旁白 4、敌人 1**；引用形式：完整 32、半句 2；保留原句 31、改动 3（改动全是「汝→我」或词序）。

这张分布说明：**"命定"的说话权高度集中在角色自己手里，但"原文出现"与"兑现宣告"之间隔着一整套他人的转述与解释。** 13 条神谕里，大多数在剧情中至少被三个人说过：旁白、他人、本人。

## 3.2 谁替谁念：接管的极端个案

**海瑟音替刻律德菈念 O11。** O11（刻律德菈）全篇唯一出现处 #20228 由**海瑟音**说出：「汝将于天地境界之海完成征服，长眠于涛声中——」；紧接着 #20229 她念自己的 O10（词序相反）。**刻律德菈本人从未引用过任何一条神谕**——这是 13 条中唯一一条"持有者在自己的神谕里完全缺席"的。

**白厄背得出别人的神谕。** #17080 白厄（卡厄斯兰那）念：「汝将碎作千片，凋零在他乡的土壤。」——这是缇宝的 O02。一个人能背出另一个人的命定，说明神谕在剧情中已从"个人命运"变成"公共知识"。

**敌人也会引用。** #10237 阿格莱雅以神谕回击赛飞儿：「汝将与贪婪同行，亦将亡于分文。」——引用者不是持有者，但引用本身构成一种"审判"。

## 3.3 从出现到兑现的距离

按 `order` 计算"首次引用 → 兑现事件段"的步差（`oracle-fulfillment.v2.json` 的 `event_segments`）：

| 神谕 | 首次引用 | 兑现事件段 | 步差 |
|---|---|---|---|
| O03 万敌 | 3.1 | 3.1（王座） | +253 步 |
| O01 阿格莱雅 | 3.1 | 3.4（回返） | +238 步 |
| O04 遐蝶 | 3.1 | 3.2（摇船|19） | 正 |
| O13 昔涟 | 3.7 | 3.4（点燃|7）+ 3.7（魔女|21） | 两段 |
| O10 海瑟音 | 3.5 | 3.5（大海|14） | **−8 步** |

- **正距离 8 条**：命运被预告后，角色走完一整段路才兑现；
- **步差 0 共 5 条**（O02/O06/O11/O12/O13 等）：神谕一次性出现即在兑现附近，谈不上"接管"；
- **O10 为 −8 步**：3.5 的嵌套闪回让语料顺序 ≠ 故事时间（`order` 是任务页顺序），这是全篇最明确的"时间轴陷阱"，报告与图注都必须注明。

## 3.4 镜像对 O10/O11：引用与兑现的交叉

两条神谕词袋相同、只换语序（见 2.4）。引用的分布是**单向**的：

- O10 的引用者：海瑟音（本人，#20229）；
- O11 的引用者：**海瑟音**（他人，#20228）——刻律德菈 0 次。

兑现层面出现"**分句交叉**"：

- 刻律德菈在「天地境界之海＝一汪浅浅的死水」中死去、耳边是涛声 → 对应 O10 的「长眠于涛声中」；
- 海瑟音被赠予「天地境界之海」，却选择留在自己的海洋 → 对应 O11 的「于天地境界之海完成征服」被主动放弃（反转）。

这是本报告最"文本内部"的发现：**两条命定的词序被交换，兑现也被交换**。词面方法（TF-IDF 全等）完全看不出这层关系，只有把引用、兑现与人物关系放在一起读才成立。

## 3.5 弱趋势：从他人转述到本人宣告

按 13 条神谕看首次与末次引用：

- 首次引用时**本人 5/13**；末次引用时**本人 8/13**、末次为「结局宣告」7/13；末次旁白 0；
- 去掉 5 条步差 0 的神谕后，"真实弧线"只剩 8 条，其中 5 条以结局宣告收尾。

**方向一致，但样本量不足以做统计推断**。报告的写法应当是"结构性 + 弱趋势"，不能写成"角色必然从被动转向主动"。

## 3.6 统计证据与局限

- 阶段/引用者/形式分布：`data/config/oracle-citation-coding.json`（34 条，逐条 evidence 可回原文）；
- 时间轴：`data/reports/oracle-citation-timeline.md`（13 条逐条时间轴）；
- 镜像对：`data/reports/oracle-citation-timeline.md` 的镜像对专项 + `f14`（配对数据 `data/plot_data/f14_mirror_pair_O10_O11.csv`）；
- 神谕相似度曲线（14 角色）：`docs/report/oracle-similarity-curves.md`（用于辅助判断"角色何时在谈神谕"，不当作含义强度）；
- 局限：34 处是关键词匹配 + 人工编码，可能有漏引；O10/O11 的 #20228 被两条同时收录（已注明）；3.5 嵌套闪回导致 `order` ≠ 故事时间。

## 3.7 小结

1. 引用的主体分布显示：命定的说话权最终回到角色自己（本人 19/34），但中间经遍布旁白与他人；
2. "谁替谁念"的个案（海瑟音代念 O11、白厄背缇宝神谕）说明神谕是公共知识而非私人预言；
3. 镜像对 O10/O11 的引用与兑现交叉，证明**命定的归属由引用者与兑现方式决定，而非词语**；
4. 从转述到宣告只是弱趋势，不能过度宣称。
