## 1. 分版本弧线

**3.0｜"拍照的美少女"：把相机交给别人，把自己留在门外。**
开场她用一句「好久不见列车长『喂喂』起手！」（#2）抢话，随即替翁法罗斯拉票——「那是一个完全未知的世界哎，还有什么比它更适合『开拓』？」（#160）。出发前把「相机储存空间」（#168）和「落地就去拍两张」（#204）、「留下一张大家都满意的合照」（#206）当成头等大事。跃迁后她病倒（#283–#290，「美少女怎么会生病呢」#288），把相机塞给开拓者：「说好落地要拍照的，这下只能拜托你啦」（#306），并留下两句日后全部兑现的伏笔：「下次见面，咱就变回那个活蹦乱跳的美少女了」（#314）、「咱们遇见的第一个当地人，肯定藏着不得了的大秘密」（#316）。**本版最后一条她的台词不再由她本人说出**——重渊拍照段出现画外音「醒~醒，该按快门啦！」（#455，形态＝幻象），而她此时已在医疗舱里。

**3.2｜两条台词，全在"别回头"的一段里。**
她在 3.2 只有两句：「开拓者，这边这边！」（#11407）与「开拓者，千万别回头啊」（#11416）。两句都嵌在主角冥界回返的**众声段**中（同段还有姬子、瓦尔特、丹恒、卡芙卡、流萤、迷迷、阿格莱雅、万敌、白厄），紧接其后是丹恒的「生死有命，但不是现在」（#11417）。她的功能与迷迷重叠：都是「把开拓者叫回来」的声音（#11451–#11452）。

**3.4｜命途狭间：她第一次、也是唯一一次为自己做决定。**
58 条，是她翁法罗斯线里最密的一段（8.7%），全部发生在「命途狭间 / 记忆之门」。识破假符玄与假丹恒（#15605「虽然你们和我认识的开拓者和丹恒很像，但是……」）、拒绝忆庭的承诺（#15612）、与被误当成敌人的昔涟结盟（#15647「这让我更想相信你」），最后否定昔涟「回头才是家」的劝告：「我决定走进这扇门，进入翁法罗斯」（#15658），理由不是找记忆而是找同伴：「唯一能被称作『家』的地方……就是伙伴们在的地方」（#15660–#15661）、「探索、了解、建立、连结——然后，我们会一起回家！」（#15665）。被夸时照例把话挡回去：「…这种话，下次让别人来说啦！」（#15670）。收尾她答应帮昔涟（#15675）——这条承诺在 3.6 由长夜月以「「往昔的涟漪」是她把这团火藏进了「岁月」的长河」（#19100）兑现。

**3.5｜两副假面：忆庭用她的脸骗人，长夜月用她的名字救人。**
先是 17 条「三月七？/！/…」——流光忆庭忆者借她的形貌诱骗开拓者去取「记忆的起点」（#19057–#19075），被识破时自嘲：「果然，仅凭记忆的掠影，无法骗过『无名客』的牵绊呢」（#19057）。随后长夜月登场，第一句就自报家门：「翁法罗斯的三月，属于永夜之帷的时间…暂时以长夜月这个称呼，将我放进你的回忆中吧♭」（#19094），把「负世」的火种当作交易筹码（#19098–#19100），末句是「为了你记忆中的『三月七』……前进吧♭」（#19108–#19110）。**这一版她本人一句真话都没说出口**，全部由冒牌货与"影子"代说。

**3.6｜她的主版本（429 条，64.6%）：97 天、两次交易、一次合一。**
- `长夜啊|2`（闪回）：她比开拓者、丹恒先一步进入翁法罗斯，被权杖格式化成「无人知晓的幽灵」，97 天走遍世界却「没有任何人能看见你」（#20561–#20564）；为了护住同伴，她与记忆里的另一个自己成交：「那就来吧，献出『我』全部的记忆……」（#20601）→「被『忘却』的浪潮吞没吧」（#20603）。
- `旅者啊`：电话诱饵用的是她 3.0 的口头禅「喂喂喂？是开拓者吗？」（#20867，形态＝幻象），「长夜」则宣称「我们是她的忆灵」（#20913）。
- `大墓啊`：长夜月对黑天鹅复盘整条因果——「我，就是那烛光映出的影子」（#20503）、她「早在你和丹恒来到翁法罗斯前」就先一步进入（#20501）、起点在无名泰坦大墓（#21943），并以三月七视角回放被「权杖δ-me13」封装的全过程（#21962–#21984）。
- `重逢啊`（K33）：长夜月先抛出电车难题（#22467–#22473），再与"藏在相机里"的三月七对质；三月七的核心反驳不是战力而是资格——「我们…有什么资格替别人做出决定呢？」（#22551）、「『开拓』的意义是『探索、了解、建立、连结』」（#22555），并把本体交给对方看：「构成它的记忆，全部来自相机中的照片」（#22571）。两人互认「同一面镜子映出的表里」（#22679）后合一（#22681），长夜月留下祝福并退场：「『忘却』会守望你的来路，如长夜般隐秘，永远安宁♭」（#22738）。
- `诸神啊`：她替「岁月」发言「就让『岁月』守望过去，指引未来——」（#22845）；长夜月的"告别碎片"再出现一次，留给她与开拓者一个问题（#22935–#22936）后彻底消退（#22948–#22949）。

**3.7｜从"人"变成"泰坦"，再变回"作者"。**
她成为泰坦 **「永夜之帷，三月七」**（64 条），以分身水母远程传话（#23308）：公民颂词把她与黄金裔并列念出——「歌颂『永夜之帷，三月七』，您为我们珍藏起岁月，将『记忆』织成繁星」（#23339）。履行「岁月」神力时她把祷言念错（「揭开记忆的被褥——」#24334，丹恒吐槽「要是能把祝词念对，还能更厉害些」#24337），3.4 的口头禅也被回收：「都说了，这种话让别人来讲啦」（#24359 ≈ #15670）。终局创世十二月的唱段里，她分到「长夜月」这一月：「长夜月，我将『记忆』织作群星——」（#25304）。战后她不参加黄金裔的告别（因为她活着），只以亲历者身份要求「给这个故事添上最后的几笔」（#25794），并给出全篇她最重要的一句：「如果岁月是个无穷的轮回——那就忘掉不断重复的苦涩，单独记住每个快乐的瞬间吧！」（#25797）。最后她与丹恒、开拓者一起续写《如我所书》（#26169「…喂喂，别写得那么急啦！」、#26178）。

## 3. 低存在感发现（轨迹表深读覆盖 6/53 = 11.3%，未读版本 3.0/3.4/3.5）

### 3.1 3.2 只有 2 条台词（0.3%），且被写成"众声之一"
全库 664 条里 3.2 只占 2 条（#11407、#11416），夹在 9 位以上角色 + 迷迷的"别回头"合唱里；她的两句甚至不是最响的那两句（真正推动剧情的是丹恒 #11408 与卡芙卡 #11418–#11419）。**发现**：这是她能级最高的"功能性出场"——不承担信息、只承担"拉住主角"的手；而她的「千万别回头啊」（#11416）与 3.6 里自己「97 天走了世界每个角落却没人看得见」（#20562–#20564）构成反向映照：**她自己才是那个一直回头、一直走不进世界的人**（判读）。

### 3.2 3.1 / 3.3 零台词：缺席本身就是她的叙事位置
轨迹表分版本矩阵显示 3.1 = 0、3.3 = 0。这不是数据缺失：3.1（王座/门扉/来路）与 3.3（金丝/黎明）正是黄金裔死亡与阿格莱雅主线的两段高潮，而她在设定上正处于"97 天幽灵期"（#21992）。**发现**：语料层面**没有任何提示**告诉读者她缺席——读者要等到 3.6 才知道这两个版本她"在场但不可见"。也就是说，**她的低存在感不是分析者的抽样偏差，而是文本刻意留白**；但这也意味着 B 组单列角色在任何"按出场量/按步骤覆盖"的统计里都会被系统性低估（3.0–3.5 六版合计仅 146 条，占 22%）。

### 3.3 3.4 命途狭间（轨迹表标为"未读"，6 步 58 条）：她唯一一次自主决断整段没被读
这段是她人物弧线的支点：拒绝忆庭（#15612）、识破两次假扮（#15605、#15638）、选择进入翁法罗斯（#15658）、给出全篇她的"开拓"定义（#15665）。**发现**：她在此处的选择标准与黄金裔的"牺牲/命定"逻辑**方向相反**——她不是为世界、不是为记忆、也不是为真相，只为"伙伴在的地方"（#15660–#15661）。这条动机在 3.6 被长夜月完整继承（#20543「她唯一的愿望，就是『开拓』的旅途能一直继续下去」），因此 3.4 是理解 K33 的前置条件。

### 3.4 3.5（轨迹表标为"未读"，3 步 54 条）：54 条里 17 条不是她

## 4. 精读独有观察（统计 / 曲线看不出来的东西）

### 4.1 3.0 的画外音「该按快门啦」（#455）是"她已在相机里"的第一次漏出，比机制揭示早 6 个版本
#455 是形态＝幻象的**首条记录**（3.0，1/96），出现在开拓者拍照段，前后文是「如果三月七此时在你身旁，她一定用少女的脑回路为眼前的景观找到奇妙且跳脱的譬喻。可惜，现在只能由你来代行团队摄影师的职责了」（#449）。3.6 才揭示机制：「当我听见开拓者按下快门的声音，就算精神只留下一点点残余……也会『咻』地一下，自己钻进相机里去！」（#22525–#22526）。**所以 3.0 那句不是幻觉，是她在相机里听见快门后的回应**（判读，置信中高：形态标签 + 位置 + 后文机制三重印证）。这也解释了为何她 3.6 能靠「照片」重造本体（#22571）——她一直依附在快门上。

### 4.2 长夜月 273 条里「咱」0 次、「本姑娘」0 次，♭ 只属于她——形态不是标签，是两套语域
| | 咱 | 本姑娘 | ♭ |
|---|---|---|---|
| 长夜月（273） | 0 | 0 | 8 |
| 无形态（228） | 19 | 8 | 0 |
| 幻象（96） | 3 | 2 | 0 |

**「咱/本姑娘」是三月七的口头人格，「我 + ♭」是长夜月的书面人格**；合并后（永夜之帷）她取回「咱」（#23034「咱俩都成了新世界的一部分」）但把 ♭ 留在长夜里。**可行性要分开说**：① **长夜月 → 三月七 方向 100% 可分**（273 条 + 另记的 13 条 = 286 条，0 次「咱」0 次「本姑娘」；♭ 只出现在长夜月一侧）；② **冒充者 → 本人 方向分不开**——3.5 的忆者刻意模仿她的口癖，一样说「咱们」（#19064、#19066），只有 `speaker` 后缀与"她们在替忆庭要东西"（#19063–#19075）能区分。这条限制本身是个结论：**能被模仿的是口癖，不能被模仿的是语境**。

### 4.3 身份认证靠成语接龙，不靠脸——3.5 与 3.6 是一对镜像
3.5 冒充者被拆穿的判据是"牵绊"：忆者能复制记忆，却复制不了默契（#19057）。3.6 反过来用默契认回她：开拓者「观隅反三……」、丹恒「君命无二……」、开拓者「凭城……」——**只有她能接上「借一？」**（#22692 标为「长夜月」？，随后 #22699「当然是我啦。」）。**发现**：文本用"是否接得上半句成语"替换了"是否长得像"，把身份问题写成语言问题——这与全篇"命定是被说出来的"总论点同构（判读）。

### 4.4 「忘」的两种用法：长夜月删掉缺陷，三月七留下快乐
长夜月的方案是「让我过滤你的记忆，留下合适的种子，剔除其余所有」（#20522）、「凡人、缺陷者、失败的英雄…只会成为『记忆』的杂质」（#20533）；三月七在 3.7 的定稿是「忘掉不断重复的苦涩，单独记住每个快乐的瞬间」（#25797）。**同一个动作（选择性遗忘），一个用于清洗世界，一个用于保存幸福**；两句都用"忘"，前后相隔 300 余条记录。这是全篇她与长夜月真正的分歧点，也是她"回收"对方而非消灭对方的方式（#22675「谢谢你的…溺爱」）。

### 4.5 「长夜月」是历法里的一个月名，而 3.7 由她来念
终局创世唱段是十二个月的排比：「门关月，我令…」（#25288）、「欢喜月…」（#25289）、「平衡月…」（#25290）、「拾线月…」（#25292）、「收获月…」（#25293）、「机缘月…」（#25294）、「纷争月…」（#25299）、「哀悼月…」（#25300）、「长昼月…」（#25301）、「耕耘月…」（#25303）、**「长夜月，我将『记忆』织作群星——」（#25304，说话人＝永夜之帷，三月七）**、「自由月…」（#25305）。**十二个月名里"长夜月"正是她那一格**。这解释了她为何在 3.5 说「翁法罗斯的三月，属于永夜之帷的时间…暂时以长夜月这个称呼」（#19094）——那个"敌人的名字"从一开始就是**她的月份**；3.7 不是原谅敌人，而是把自己的名字念回自己的位置。

### 4.6 97 天的弓，最后射进了铁墓
`落英|4` 回放她 97 天的战斗方式：「她以手中的弓箭，狠狠教训了拦路的家伙们」（#25969），昔涟紧接着说「我之所以能如此熟练地拉弓，都要归功于三月呢」（#25971）；而 3.7 的决胜一箭正是弓：黄金裔化作弓（#25328）、昔涟从身后握上开拓者的手（#25329）、「你们一起将箭矢射出」（#25330）。**她的 97 天没有白过，而是变成了别人手里的弓**（判读，置信高：文本明说"归功于三月"）。

1. `character-trajectory-all.md` §5 记「三月七 未读版本：3.0、3.4、3.5」——本次 L3 已把这 3 个版本（14 步 / 144 条）全部读完，覆盖率不再是 6/53。
2. 同一报告「深读覆盖 6/53 = 11.3%」是以 K33/30/74 文件实际内容计；本笔记的 53/53 是**上下文表口径**，两个数字不冲突，但报告里必须区分「L2 上下文全读」与「K33 等场景级深读」。
3. 「664 条」这个数字包含 17 条忆庭冒充者 + 2 条「长夜月？」诱饵（§5 U4），**并且漏掉**另记为独立角色的长夜月 13 条 + 「？？？」2 条（§4.10）；**若要写"三月七本人说了多少"，应写 208 条（无形态本人）或按形态分列**，不宜直接用 664。
4. `knife-scenes.json` K33 的 `type` 为「离别/身份揭示/自我否定」，`why` 已准确；但该场景 `ranges` 只到 #22681，**长夜月真正的告别（#22726–#22738）落在下一段 `重逢|3`**，引用"最后一次行使忘却"时须引 #22730–#22732，而非 K33 区间内。另：K33 的 `type` 里没有「合体/合一」，而 E23 的 event_name 是"合一"，两处口径可对齐。
5. `key-events.json` E23（三月七与「长夜月」合一）`evidence_record_id=22679`，与本笔记一致；E23 的 `meaning_before` 把长夜月写作"占据三月七身体、意图牺牲开拓者的敌人"，本笔记的补充是：**长夜月从未主张牺牲开拓者，她的方案是"让开拓者睡在记忆里、由她烧尽世界"**（#22435–#22444、#20522–#20525），措辞若照 E23 直引会失真。
6. 报告若要用她做「B 组不参与黄金裔比较」的例子，可用的**唯一**正向交叉点是 3.7 的泰坦名录与英雄名单（#23339、#26119–#26122）：她在两处都被计入，而两处都不把她当黄金裔讨论——这正好说明「名单位置」与「血统/组别」是两件事。
