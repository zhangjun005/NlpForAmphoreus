# 歌词《昔涟》向量分析：分析逻辑（供前端转换参考）

> 这一页只记录**分析是怎么做的、结果是什么、能说明什么/不能说明什么**，不写前端实现。
> 数据产物：`data/config/lyric-query-xi.json`、`data/plot_data/query_xi_lyrics.json`；脚本：`tools/lyric_query_report.py`、`tools/encode_text.py`。
> 用途：前端新增一页"篇外语料：把一首歌词放进语料空间"时可据此拆面板。

## 1. 这一页想回答什么

> 如果把官方角色曲《昔涟》的歌词放进"角色台词向量空间"，它**在数值上最接近谁、最接近昔涟的哪个阶段、最接近哪条神谕**？

注意：这是"向量接近程度"问题，不是"歌词证明了角色是谁"。

## 2. 输入

- **查询文本**：用户提供的《昔涟》歌词全文（24 行，存为 `data/config/song-lyrics-xi.txt`）；
- **语料**：26,332 条台词/旁白/选项（`data/corpus/amphoreus.final.jsonl`）；
- **已有向量**：每条台词的 TF-IDF 向量与 512 维句向量（`data/models/vec_rec.joblib`、`Z_sbert_rec.npy`）；
- **角色向量**：14 个角色的质心（`data/models/character_centroids.npz`，含按版本质心）；
- **神谕文本**：13 条（`data/corpus/oracles.jsonl`）。

## 3. 分析步骤（五步）

1. **编码**：把整段歌词分别编码进两个空间——
   - TF-IDF（词面向量）：看"字面用词像不像"；
   - 句向量（SBERT/bge-small-zh-v1.5，512 维，语义向量）：看"意思像不像"。
2. **与 14 个角色质心比较**：每个角色有一个"质心向量"（该角色全部台词向量的平均），算余弦相似度，排序。
3. **与昔涟的 8 个"分版本质心"比较**：把昔涟台词按版本分别平均，看歌词最像哪个阶段的她。
4. **与 13 条神谕比较**：歌词更像"谁的命定"（不是看"昔涟自己的 O13"是否最高，而是看排序）。
5. **找最接近的台词**：把歌词与全部 26,332 条台词算相似度，取 Top-k。
   - **关键处理（自我匹配排除）**：语料里本身就有这首歌的歌词块（`3.7|落英|11`，#26218–#26241），若不排除，Top-k 全是歌词自己；所以"最近台词"列表**排除这 24 条**，剩下的才是"歌词 vs 角色台词"的对照。
   - 同时保留"歌词 vs 语料内歌词块"的相似度（0.688），用来说明两版文本的接近程度。

## 5. 结果怎么读（三条）

1. **它是昔涟的歌，向量也指向昔涟**：14 个角色里排第 1，且与昔涟 **3.7（收梢/告别）** 最接近——和歌词"最后这一页/道别/续写起点"的主题一致。
2. **但它更接近 O04（遐蝶的"相拥→永恒离别"）而不是 O13（昔涟自己的"收梢于花开时"）**：歌词的"再见/思念/道别"语义，在向量空间里更贴近"离别"那条神谕。→ 这说明**"自己的神谕"不会自动最像自己**，向量相似度不能直接当"命定归属"。
3. **与三月七（0.584）非常接近**：歌词里的"岁月/书/记忆/再见"和三月七的长夜月线共享同一批词与意象，属于"语料里主题相近"而非"歌词在讲三月七"。

## 6. 不能说什么（前端必须显示的口径警告）

- 这是**一首歌 vs 一个角色 2,393 条台词**：SBERT 整体在 0.5–0.6 的叙事基线，**差值只有 0.02–0.05**；
- **相似度 ≠ 含义**：不能说"歌词证明了她是谁"，只能说"在向量空间里最接近 3.7 的她"；
- TF-IDF（词面）与 SBERT（语义）会不一致：如对 O02/O09/O11，TF-IDF 几乎为 0，SBERT 却有 0.42——两套结果要分开显示；
- 歌词里包含标题/分段差异，与语料内歌词块（#26218–#26241）并非逐字一致（最高 0.688）。

## 7. 前端可用的数据契约（字段说明，不是实现）

数据文件：`data/config/lyric-query-xi.json`（完整）+ `data/plot_data/query_xi_lyrics.json`（逐条 Top-k 原始结果）。

```
{
  "note":       "说明口径",
  "lyrics_chars": 620,
  "char_centroids": [ {char, sbert, tfidf} ×14 ],       // 4.1
  "xi_version_centroids": [ {version, sbert} ×8 ],       // 4.2
  "lyrics_self_block": {n:24, max_sbert:0.688, sample:[...]}, // 自我匹配信息
  "top_non_lyric_lines": [ {record_id, version, task, step_idx, speaker, text, score} ×15 ], // 4.4
  "oracle_similarity": [ {oracle_id, holder, text, sbert, tfidf} ×13 ]  // 4.3
}
```

对照数据（同模块可并排展示）：`data/plot_data/query_xi_lyrics.json` 里还有 `char_topk_sbert` / `char_topk_tfidf`（歌词对昔涟本人台词的 Top-k）。

## 8. 复现

```bash
conda run -n nlpLesson python tools/lyric_query_report.py          # 生成 4.1–4.4 汇总
conda run -n nlpLesson python tools/encode_text.py \
  --file data/config/song-lyrics-xi.txt --char 昔涟 --topk 12 \
  --out data/plot_data/query_xi_lyrics.json                         # 逐条 Top-k
```
