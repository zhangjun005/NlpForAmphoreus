# 前端数据覆盖表

这张表是前端接入项目产物的验收表。`展示位置`指用户在页面上可以看到的组件；`回溯方式`指组件能回到的最小数据单位。

| 数据对象 | 关键字段 | 前端组件 | 展示位置 | 回溯方式 | 状态 |
|---|---|---|---|---|---|
| 剧情步骤 | `segment_id`、`version`、`task`、`step_title`、`main_records` | `StepEvidence` | 证据层 | 步骤 → 记录号 → 说话人和原文 | 已接入 |
| 神谕 | `oracle_id`、`text`、`holder`、`titan`、`event_segments` | `OracleStory` | 神谕履历 | 神谕 → 引用记录 → 兑现段 | 已接入 |
| 神谕引用 | `record_id`、`segment_id`、`stage`、`citation_form`、`text` | `citation-ledger`、`DataTrace` | 神谕履历 | 引用 → 任务、步骤、原文 | 已接入 |
| 关键事件 | `id`、`meaning_before`、`meaning_after`、`evidence_record_id` | `Evidence` | 证据层 | 事件 → 证据句 → `record_id` | 已接入 |
| 显著性标注 | `segment_id`、`significance`、`types`、`note` | `Evidence`、`DataTrace` | 证据层 | 标注 → 步骤 → 说明 | 已接入 |
| 角色曲线 | `order`、`version`、`task`、双空间原始值/滚动值、事件标记 | `FullRoleCurve` | 角色轨迹、重点分析 | 点 → 版本、任务、步骤、事件标记 | 已接入 |
| A/B1/B2 排名 | `rank`、`score`、`segment_id`、特征组 | `RetrievalChart`、`FailureCases`、`DataTrace` | 方法边界、实验材料 | 排名 → 步骤 → 特征贡献 | 已接入 |
| 刀子场景 | `id`、`segment_ids`、`record_span`、角色和强度 | `SupplementaryData`、`FailureCases` | 实验材料 | 场景 → 步骤 → 记录范围 | 已接入 |
| 语体比较 | G1/G2/G3 特征均值 | `SupplementaryData` | 实验材料 | 特征 → 语体组 → 原始快照 | 已接入 |
| 告别回收 | 角色、`verdict_counts`、Top-5 匹配 | `SupplementaryData` | 实验材料 | 角色 → 人工判定摘要 | 已接入 |
| 角色覆盖率 | 角色、版本、步骤和精读覆盖字段 | `SupplementaryData` | 实验材料 | 角色 → 覆盖摘要 | 已接入 |

## 当前明确不展示的内容

- 原始 BWiki wikitext 和完整游戏台词不公开；前端只使用已归档的派生快照。
- 句向量本体、TF-IDF 矩阵和 SBERT 模型不在浏览器端加载；页面展示它们生成的可复核结果。
