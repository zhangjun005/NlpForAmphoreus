# 项目状态与前端目标

## 项目是什么

项目使用翁法罗斯 3.0–3.7 主线语料，研究“命定如何被写进语言、被角色认领与改写”。当前语料工程已完成：26,332 条记录、723 个步骤、13 条神谕、34 次引用、30 个关键事件、36 个刀子/高光候选场景。

AnalysisV2 已经把项目从“模型实验集合”推进到“剧情解释为主、统计作证据”的报告结构：

```text
命定如何被写成语言
→ 命定如何被角色接管
→ 命定如何被兑现、反转或错位
→ 叙事显著性检测的能力边界
→ 告别、明天见、水晶花与收梢的闭环
```

## 前端要解决的问题

前端只需要把课程项目从头到尾讲清楚：

> 我们如何把剧情文本交给 NLP 处理，又如何从处理结果回到“命定的含义发生了什么变化”。

## 线性讲解顺序

1. 原始剧情是什么样；
2. 如何把网页文本整理成一条条可追溯的记录；
3. 如何识别神谕、角色、引用和事件；
4. 如何把文字变成 TF-IDF、BM25 和句向量等可计算表示；
5. 如何用这些表示寻找引用和相似片段；
6. 为什么相似度不能直接等于“含义”；
7. 如何结合引用顺序、角色关系和剧情上下文解释白厄与昔涟的主线；
8. 最后说明方法得到什么、不能得到什么。

每一步都固定讲四件事：**方法是什么、原理是什么、为什么使用、文本变成了什么**。
