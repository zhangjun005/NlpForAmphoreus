# 第 0 章 故事梗概

翁法罗斯是一座被黑潮围困的世界：大地沉入永夜，唯剩圣城奥赫玛在刻法勒的庇佑下亮着最后一点光。十二泰坦早已疯狂，人们把希望押在「逐火之旅」上——由黄金裔接过十二枚火种、完成「再创世」，让破碎的世界重获新生。每位黄金裔生来都背着一句神谕，命定像钉子一样钉在他们身上；可「再创世」本身是一场骗局，世界被锁在一次次重演的循环里。

黄金裔们逐一登场，也逐一退场。万敌亲手终结了悬锋王朝，把母亲留下的印戒交给失去身份的人，也把「背后负创而死」的弱点亲手交给了白厄；阿格莱雅以「最后一次沐浴」把神谕在自己身上兑现，而她的谢幕是另一场设计好的死；缇宝把「明天见」当作最伟大的预言送给众生；那刻夏以渎神者的身份求证真理，把自己炼进「理性」的火种；海瑟音与刻律德菈各执一条词序颠倒的镜像神谕，一个长眠涛声、一个改写律法，最终谁也没能按字面兑现；赛飞儿用一个谎言维系奥赫玛的永昼，最终死在自己那句「分文」上——那枚硬币既是渡冥河的摆渡费，也是她的瞬移媒介；遐蝶把「相拥之后便是永恒的离别」读成「拥抱就是爱」；风堇接过「天空」，成为缝补晨昏的人；荒笛则把「大地」留给后来者。

来自星穹列车的开拓者、三月七与丹恒，原本只是误入此地的外来客，却在送别一位位黄金裔的路上，从被当作「救世主」的贵客，变成愿意接过「负世」职责的参与者。真正撑起三千万次轮回的是白厄与昔涟：白厄一次次回到起点，把失败重走成下一次尝试；昔涟把「岁月」剪成可以重写的一页，替他把「救世主」的预言写成希望。最终白厄亲手把「救世主」之名交了出去——「愿这名号能代我同行」，命定成了他留给后来者的东西；昔涟则把自己的「收梢」写成「起始」：花在旅途的终点收梢，又在起点生根。

故事落到一本叫《如我所书》的书上。它起初只是昔涟童年那副神谕牌册，后来成了记录银河众生记忆的书；被写下的英雄，最终成了自己写书的人。「明天见」也一路改写：从母亲临终的安慰、从遐蝶口中那个「善意的谎言」，变成黄金裔们共同的预言与誓言。于是结尾没有句点，只有一句「明天见，乘以一千」——收梢即起始，告别即重逢。
