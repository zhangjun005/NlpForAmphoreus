# NLP 方法教学链路（线性版）

这一页就是前端的主讲稿。每一步只回答四个问题：**方法是什么、原理是什么、为什么用、文本变成了什么**。

## 第 1 步：把网页剧情变成记录

- **方法**：清洗、分段、字段化。
- **原理**：把每条对白或旁白和它所在的版本、任务、步骤、说话人绑定起来。
- **为什么用**：否则后面找到一句话时，无法知道它在剧情中的位置。
- **变成什么**：一条长网页文本变成 `segments.jsonl` 中的记录，例如“3.4 / 任务 / 步骤 / 说话人 / 台词 / 顺序”。

## 第 2 步：统一角色和剧情顺序

- **方法**：别名归一、形态保留、顺序编号。
- **原理**：把“赛法利娅—赛飞儿”“迈德漠斯—万敌”等名称映射到同一规范角色，同时保留原称呼。
- **为什么用**：同一角色换名字后，不能被误算成两个角色。
- **变成什么**：每条记录多出 `canonical_speaker`、`form`、`version`、`segment_index` 等字段。

## 第 3 步：抽取神谕和引用

- **方法**：规则匹配 + 人工核对。
- **原理**：神谕句式稳定，先用固定文本和关键词找到候选，再标记谁说、何时说、是否原样引用、是否改写。
- **为什么用**：固定句式适合规则方法，结果容易追溯，不需要黑箱模型猜测。
- **变成什么**：得到 13 条神谕、34 次引用，以及“原文出现—他人解释—本人引用—结局宣告—改写反转”等阶段标签。

## 第 4 步：把文字变成词面特征

- **方法**：分词、TF-IDF、BM25。
- **原理**：TF-IDF 给片段中的重要词加权；BM25 在检索时同时考虑词频、稀有度和文本长度。
- **为什么用**：先建立一个简单、可解释的词面基线，看看神谕词语能否找到相关剧情。
- **变成什么**：文字变成词权重和排序结果，例如“背后负创”会把含有该词的片段排到前面。

## 第 5 步：把文字变成语义向量

- **方法**：句向量 + 余弦相似度。
- **原理**：模型把一段文字映射成向量，向量方向越接近，表示模型认为语义越接近。
- **为什么用**：有些剧情不重复神谕原词，但可能表达相近的关系或结果。
- **变成什么**：每个片段变成一个向量，并可得到随剧情顺序变化的相似度曲线。

## 第 6 步：分析引用关系和文本风格

- **方法**：引用阶段编码、词汇/句式统计、话题匹配。
- **原理**：记录神谕从谁的口中出现、被谁解释、是否被本人认领；同时比较第二人称、情态词、文言词和句长等特征。
- **为什么用**：项目关心的是“谁如何使用命定”，不能只看相似度；语体比较还要避免把话题差异误当成风格差异。
- **变成什么**：得到引用轨迹、角色间的接管关系，以及“神谕语体”和对白语体的可比较特征表。

## 第 7 步：用结构特征找叙事显著片段

- **方法**：A/B 候选排序。
- **原理**：A 主要看词面和局部情绪；B 在此基础上加入身份变化、语义突变、母题回收和结构位置。
- **为什么用**：比较普通词面检测和加入叙事结构后的结果，观察哪些“词不重但含义重”的片段被补回来。
- **变成什么**：每个步骤得到一个候选分数和排序；它只是找人工阅读入口，不是文学意义的最终判断。

## 第 8 步：回到原文解释含义变化

- **方法**：人工精读 + 证据链整理。
- **原理**：把模型找到的片段放回前后文，比较角色、说话人、事件和意象的变化。
- **为什么用**：相似度只能说明“像不像”，不能说明“命定在这里被谁改变成了什么”。
- **变成什么**：形成最终报告中的“原文—处理结果—剧情解释”链条。白厄与昔涟是重点分析对象，其他黄金裔与列车组成员也沿用同一套证据格式展示。
