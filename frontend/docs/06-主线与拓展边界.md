# 主线与拓展边界

## 主线

主线是课程展示本身，保持一条线性流程：

```text
原始剧情
→ 结构化记录
→ 角色与顺序规范化
→ 神谕/引用/事件抽取
→ TF-IDF 与 BM25
→ 句向量与相似度
→ 引用关系与叙事结构
→ 白厄与昔涟的重点分析
→ 结论与限制
```

主线页面只展示能帮助听众理解这条流程的必要数据。每一步可以有一个真实的小例子，但不需要把所有中间文件或所有图表都放进页面。

## 拓展

拓展区保留给后续的小功能和实验。本次不改动拓展内容，也不把拓展功能混入主线讲解。未来如果加入拓展，只在主线结束后以“进一步尝试”的形式出现，并明确它不是主结论所必需的部分。

## 判断标准

一个内容只有在能回答“这一步处理后，文本变成了什么”时，才进入主线。只适合搜索、玩具演示或额外探索的内容放在拓展区。
