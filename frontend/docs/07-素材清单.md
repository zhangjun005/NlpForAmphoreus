## 建议优先收集的素材类型

1. 官方媒体包中的主视觉或无文字背景；
2. 官方角色页中的角色头像/立绘裁切；
3. 官方宣传页中的星轨、金色线条、花朵和水晶等抽象装饰；
4. HoYoLAB 活动贴中的贴纸，仅作为需要许可时的备选。

## 页面使用原则

- 视觉素材只做章节装饰，不遮挡原文和数据；
- 优先使用背景、边角、头像等低信息量素材；
- 每个素材旁显示来源链接或在页脚统一列出来源；
- 未确认授权的社区创作者素材暂不复制到 `frontend/public/`；
- 不下载或重新分发完整游戏原文、剧情截图和未获许可的表情包。

## 角色头像素材（补充，2026-10-26）

页面角色卡左侧的小头像统一为 **160×188、白底 PNG**，放在 `frontend/public/materials/<slug>-portrait.png`
（该目录在 `frontend/.gitignore` 里，属本机素材，不入库；换机器用下面的脚本重新生成）。

- 原有 8 张：白厄 / 万敌 / 那刻夏 / 昔涟 / 遐蝶 / 缇宝 / 海瑟音 / 刻律德菈（早期下载）。
- 新增 6 张：**阿格莱雅 / 赛飞儿 / 风堇 / 开拓者 / 三月七 / 丹恒**。
  - 来源：[StarRailRes](https://github.com/Mar-7th/StarRailRes)（社区整理的官方素材仓库）的
    `icon/character/<角色ID>.png`；角色 ID 取自该仓库 `index_min/cn/characters.json`：
    阿格莱雅 1402、赛飞儿 1406、风堇 1409、三月七 1001、丹恒 1002、开拓者 8007（记忆命途）。
  - 处理：白底合成 → 居中裁成 160:188 → LANCZOS 缩放到 160×188。
  - 复现：`conda run -n nlpLesson python tools/make_portraits.py`（脚本内写死了上面 6 个 ID 与来源 URL）。
- 页面侧映射在 `frontend/src/App.jsx` 的 `PORTRAITS`（角色名 → slug），组件仍保留 `onError` 隐藏，避免素材缺失时出破图。
