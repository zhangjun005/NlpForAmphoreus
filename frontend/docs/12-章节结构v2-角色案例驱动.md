# 章节结构 v2：角色案例驱动 + 两栏版式（按你的方向改）

> 取代 v1（v1 用"单一对象 O09 贯穿"作主轴）。v2 的主轴是**整条剧情**，每章挑 1–2 个典型角色作案例；**方法与结果在同一章、同一屏内并置**，方法用段落讲、不用 2×2 卡片。
> 数据全部来自根目录现成产物（`data/plot_data/`、`data/config/`、`data/reports/`），每章末尾附"这章用了哪些数据"。

## 0. 全局版式规则（先定死，再排内容）

1. **两栏交替**：每屏 `左图右文` 或 `左文右图` 交替出现，避免连续多屏同一方向造成疲劳；
2. **禁止 2×2 方法卡片**：方法说明一律写成 1–3 段自然段，紧贴它解释的那张图/表；
3. **一屏一个主张**：标题是"结论句"，不是"方法名"（例："白厄的命定，他几乎从不亲口说"）；
4. **图旁三件套**：图 / 一句话说明 / 数据来源（文件 + 能回原文的 record_id）；
5. **口径警告就地出现**：不用"最后统一提醒"，在相关图下直接写"这张图不能说明什么"。

## 第 0 章 故事梗概（新增）

**内容建议**（约 600–800 字，正文用段落，不用卡片）：

翁法罗斯是一个被"循环"困住的世界：黑潮反复侵蚀、十二位半神（黄金裔）逐火赴死、创世与再创世一轮轮重演。维持世界的核心是**神谕**——每位黄金裔都带着一条写好的"命定"，它决定了他们怎么死、怎么活、怎么被记住。
玩家（开拓者）与列车组（三月七、丹恒）进入这个世界后，从"外来者"逐渐变成"参与者"：他们见证了万敌的赴死、阿格莱雅的退场、缇宝的传承、那刻夏的自我处刑、海瑟音与刻律德菈的对偶、赛飞儿的谎言、遐蝶与死亡的和解、风堇的留天空，以及白厄与昔涟跨越三千万次轮回的主线。最后一轮里，白厄交出"救世主"之名、昔涟把终结改写成"收梢即起始"，《如我所书》把"被写下的英雄"变成"自己写书"——命定从"写死人的预言"变成"角色自己留下的告别词"。

**配图**：一条 3.0→3.7 的版本时间轴（已有 `f12` 与版本边界数据），标注每章案例角色出场的主要版本。

## 1. 第 1 章：两套语言测量，测的不是同一件事

> 主张：**TF-IDF 测"字面"，句向量测"语义"；两者对不上，正好说明"命定"不是单纯用词问题。**

- 左文右图：先用段落解释"分词→词频→TF-IDF"和"句向量→余弦相似度"两套方法为什么不同（词面 vs 语义）；
- 右图：用 **O10/O11 镜像对**做最干净的例子——两条神谕只换语序，TF-IDF 曲线 686 步**逐点相等（max|Δ|=0）**，SBERT 差异 ≤0.018（`f14`）；
- 再补一个反例：**刻律德菈**的曲线里，SBERT 的"最相似其他神谕"是 **O08（0.721）**，而 O10 只在词面层出现 → "镜像对"这个结论只能靠词面+引用读出，语义向量读不到；
- 段末口径：相似度不是含义强度；不适用于"哪条神谕属于谁"。

**数据**：`f14` + 配对 CSV、`oracle-similarity-curves.json`、本文档"两句话版本"。

## 2. 第 2 章：白厄——被选中者的沉默（集中在前一半）

> 主张：**他的命定他几乎从不亲口说；台词峰值其实是"身份分裂"。**

- 左图右文：图用白厄四联图（台词量/形态/称呼/分数，`f7`），文写三个数据点：
  1. 2,550 条台词里「骄阳」只出现 3 次，O09 唯一一次"本人引用"是**交出**（#16719）；
  2. **3.5 零台词**（缺席是叙事装置），3.4 台词峰值 = 白厄 425 + 卡厄斯兰那 224 + 心中的英雄 49 + 盗火行者 8 + 幼年 4（**身份分裂**，不是"戏份最多"）；
  3. 形态/称呼变化：老师→伙伴/英雄；`f7(b)` 图里"白厄（本体）"占大头。
- 方法段落嵌在图中：解释"轨迹图怎么读"（每版本台词量、形态堆叠、称呼词频），不单独开卡片；
- 段末：这张图能说明"他什么时候说得多、以什么身份说"；不能说明"他什么时候最痛"。

**数据**：`f7` + CSV、`character-trajectory-all.json`（白厄行）、`L3 白厄.md`。
