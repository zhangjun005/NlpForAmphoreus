# 翁法罗斯 NLP 交互式分析前端

这是项目的独立前端工作区。它服务于课程展示和文本分析阅读，不负责重新抓取语料，也不承担分析模型训练。

前端的主问题是：

> 神谕如何被写成语言、被角色接管、被改写，并在剧情中获得新的含义？

展示采用一条类似 PPT 的线性流程：从原始剧情开始，依次说明每一步使用的方法、原理、使用理由，以及文本在这一步之后变成了什么。

## 当前状态

- `docs/`：产品定位、项目状态、内容模型、方法教学链路和实施计划；
- `data/`：当前前端需要的数据快照和报告处理过程示例，避免 DS 后续改动影响前端设计；
- `src/`：预留前端代码目录；
- `public/`：预留静态资源目录。

当前先冻结这条讲解流程和数据快照，再实现简单页面。页面不做数据大屏，也不追求复杂交互；角色区可以完整展示全部角色，不受 PPT 页面积限制。

## 当前页面

- `index.html`：线性报告页面；
- `src/App.jsx`：线性报告页面、证据表、引用台账、角色曲线和检索诊断组件；
- `src/components/ui.jsx`：本地 shadcn 风格基础组件（Card、Badge、Button 等）；
- `src/styles.css`：Tailwind + CSS 变量、页面样式和响应式布局；
- `data/*.csv`：从根目录 `data/plot_data/` 复制的图表数据，页面直接读取这些 CSV，不嵌入静态图。

当前工程使用 React + Vite + Tailwind，并使用本地 shadcn 风格组件组织页面；图表使用 Recharts，数据从 `public/data/` 快照读取。引用、关键事件、标注和曲线都能展开查看对应数据行，角色曲线的版本边界按该角色实际出场范围计算。

构建检查：

```bash
npm run build
```

本地预览：在 `frontend/` 目录启动任意静态服务器，例如 `python -m http.server 8765`，然后访问 `http://localhost:8765/`。直接双击 HTML 会被浏览器的本地文件权限阻止 CSV/JSON 加载。
