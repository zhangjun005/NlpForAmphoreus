# 标注方法修订（对照外部建议逐条评估）

> 背景：外部（GPT）审阅后指出，当前 74 条标注应重新定位为「**LLM 辅助标注**」而非「人类 gold standard」，并建议加证据、独立双标注、分歧导向复核、机械化等级定义、保留不确定性、区分稳定性与准确率、拆分神谕的"吟诵段/事件段"。
> 本文逐条对照我们**已经做了什么**、**该改什么**、**改动对已有结果的影响**。

## 一、先给结论

| GPT 建议 | 现状 | 结论 |
|---|---|---|
| ① 标注答案 → 标注证据（record_id/quote/before/after/why_not_2） | 已有 `note`（要求引用原文）+ `confidence`，但**非结构化**，无 before/after、无 record_id | **采纳**：补字段与再标注 |
| ② 两次独立标注（互不可见） | 只有**同一 agent 隔轮重标**（等级 90%、类型 60%） | **采纳**：这正是当前最大的方法弱点；但要区分"稳定性"与"一致性" |
| ③ 人工只审分歧/等级 3/关键案例 | 用户已裁定 5 条争议、神谕 13 条已确认 | **部分采纳**：按 GPT 清单补齐抽样复核 |
| ④ 等级定义机械化（状态是否持续改变/是否重释前文） | 定义偏概念化（0–3 级），未强制三问 | **采纳**：写进标注规则 v2 |
| ⑤ 保留模糊答案（alternative_level） | 无 | **采纳**：新增字段，不改主标签 |
| ⑥ 重测一致率 ≠ 准确率 | 报告中已写"单人标注无法算 kappa" | **已一致**，但需在报告措辞上明确改为「重复标注稳定性」 |
| ⑦ 神谕拆 `recitation_segment` / `event_segment` | 只有一个 `fulfillment_segment`，且**多数就是吟诵步** | **采纳（最高优先）**：直接修复检索实验的 gold 问题 |

## 二、逐条说明

### ① 从"答案"到"证据"
当前 `annotation-labels.json` 每条有 `significance/types/note/confidence`，note 要求引用原文，但没有结构化字段。建议 v2 增加：

```json
{
  "before_state": "…", "after_state": "…",
  "evidence": [{"record_id": 23105, "quote": "…"}],
  "why_not_lower": "为什么不是 2 级",
  "alternative_level": 3
}
```
**影响**：不改已有标签，只追加字段（可对 74 条做一次补全）。

### ② 独立双标注
当前是同一 agent 隔轮重标（自我一致性），GPT 说得对：**不能让第二个 AI 看第一个的答案**。应做两个独立上下文（不同 agent，或同一 agent 在完全屏蔽前序结果的新会话），再比较。
**影响**：新增一次 74 条独立标注；产出一致率（等级 exact / 类型 Jaccard），分歧样本进入人工复核。
**注意**：我们只有 8 人上限且 `annotator` 是唯一读剧情的 agent → 可复用 `annotator`，但必须在 prompt 里**屏蔽**历史答案（不提供 annotation-labels.json，不给 L1–L7 层，不给 A/B 分数）。

### ③ 分歧导向的人工复核
人工量估计 25–40 个（两次不一致 10–20 + 等级 3 约 10 + A/B 关键差异 10 + 随机负例 5 + 神谕 13，去重后）。这比重新标 74 个少得多。
**建议优先级**：神谕 13 条（用户可直接确认）→ 两次不一致 → 等级 3 → A/B 关键差异 → 随机负例。

### ④ 机械化等级定义
在标注规则里强制三问：状态是否改变？变化是否持续？是否重释前文？按规则映射：
- 0 无持续变化；1 增加信息/局部关系；2 身份/目标/关系/世界规则持续变化；3 不可逆或前文意义被重释。
**影响**：只改规则文档与再标注 prompt，不改已有数据；报告里可用三问表解释"昔涟诞生为何是 3"。

### ⑤ 保留不确定性
新增 `alternative_level`（可选）与 `level_distribution`（可选）。主结果用主标签，争议样本单列，并做"排除不确定样本"的敏感性分析。
**影响**：不影响现有结果；报告里多一张敏感性表。

### ⑥ 措辞修正
报告与文档中把「重测一致率」统一改为「**重复标注稳定性**」，并明确：
- 稳定性 ≠ 与人类判断一致；
- 标签应分三层呈现：AI 初始标注 / 独立复核后一致标签 / 人工抽样核验标签。

### ⑦ 神谕：吟诵段 vs 事件段（最高优先）
当前检索实验失败的根因就是两者混为一个 gold：12/13 条 gold 本身是吟诵步。
**建议**：13 条神谕各填两个字段：
- `recitation_segment`：出现神谕原文/直接吟诵的步骤（可多个）；
- `event_segment`：真正发生兑现/反转/错位的步骤（人工确认）。
**影响**：
- 检索实验可重做（query=神谕原文，gold=event_segment，排除 recitation 步）；
- 神谕主线可信度提升；
- 用户的 5 条裁定可并入 `event_segment` 的判定依据。

## 三、建议的下一步工作（按优先级）

1. **神谕事件段重标**（13 条，人工/annotator 协助，最优先）→ 重跑检索 v3；
2. **独立双标注**（74 条，另一次屏蔽上下文的标注）→ 一致率 + 分歧清单；
3. **证据字段补全**（74 条 + 13 条）→ before/after/record_id/alternative；
4. **人工抽样复核**（25–40 个，分歧 + 等级 3 + 关键案例 + 随机负例）；
5. **报告口径改写**（"LLM 辅助标注"声明、三层标签、稳定性 vs 准确率、敏感性分析）。

## 五、现在可以写进报告的诚实声明（建议原文）

> 由于语料规模较大（26,332 条 / 723 个步骤实例），叙事显著性标签采用**固定规则下的 LLM 辅助标注**：每个样本要求输出等级、类型、证据台词与置信度，并通过**独立重复标注**筛选分歧样本；研究者对关键阳性样本、模型分歧样本与随机阴性样本进行人工复核。因此该标注集用于**探索性模型比较与案例分析**，不宣称为完全独立的人类 gold standard。
