# 02 · 解析器四代迭代（v1 → v3.1）

- **时间**：2026-10-23 17:06–22:13
- **目标**：把 75 页 wikitext 解析成「一行一条」的结构化语料（对话/选项/旁白/短信）。

## 实际动作

### v1（`tools/build-corpus-v3.js`）
1. 先按行切分，再清理模板 → **顺序错误**，导致 10 条正文只剩 `{{颜色`、196 条尾部残留 `}}`。
2. 只认 `==二级标题==`，而流程步骤是 `===三级标题===` → 全部记录 `step=1`。
3. 按页面标题拼音序输出 → 语料是「书/争/仇/公…」的拼音序。
4. 行首 `:` 开头的 1,963 行被整行丢弃（场景/时间跳跃旁白丢失）。
5. 产出 24,206 条（`data/corpus/amphoreus.jsonl`）。

### v2/v3 修复
6. 改成「先内联展开模板，再按行解析」：`{{颜色|x|Y}}→Y`、`{{注音|A|B}}→A`、`{{黑幕|x}}→x`、未知模板取最后纯文本参数。
7. 逐行状态机：标题→step；`*角色：台词`→dialogue；`{{角色对话}}`→dialogue+scene；`{{剧情选项}}`→option+分支；`:`→narration；`{{折叠}}`→extra。
8. 用 `前置任务/后续任务` 建链（64 边）拓扑排序，同层按 (版本, 编号) 兜底 → 顺序正确（3.0→3.7 单调）。

### v3.1（`tools/build-corpus-v31.js`，agent `parser-v31`）
9. 补 `:` 行旁白 1,817 条、选项块旁白 209 条、短信 64 条、内联对白 32 条。
10. 拆 `narration` 内嵌说话人 894 条（`永夜之帷，三月七：…` → dialogue + speaker）。
11. 修伪说话人 21 条（speaker 含句末标点）。
12. 产出 26,332 条 / 566,798 字（`amphoreus.v31.jsonl`）。

## 输入 / 输出

- 输入：`data/raw/wt-cache/*.txt`（75 页）
- 输出：`amphoreus.jsonl`(24,206) → `amphoreus.v31.jsonl`(26,332)
