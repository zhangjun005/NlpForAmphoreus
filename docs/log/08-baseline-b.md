- **目标**：在 A 的词面分项之外加入跨上下文结构特征，检验能否补上"转折深度"维度。

## 实际动作

1. 派 agent `baseline-a`（复用，task-10）实现 `tools/baseline_b.py`（TF-IDF 字符 2–3 gram + jieba；不引入 embedding）。
2. 特征（5 组）：
   - 词面组：A 的 score（z 化）；
   - **语义突变**：步骤内 `main_records` 滑窗（20 条 / 步长 10）相邻余弦距离（top20均值 0.5 / p90 0.3 / 跨步骤 0.2）；记录数<20 按口径整步 1 窗、距离=0；
   - 身份/位置：说话人与形态变化、首登场角色数、称呼词命中、任务首末步/版本切换；
   - 母题回收：`semantic_recall` + `surface_repetition` + 母题词上次出现距离 + structure/translation 率；
   - 状态变化：不可逆标记（不再/再也/永远/从此/最后一次…）。
3. 打分：`S_B = 0.50·z(A) + 0.20·语义突变 + 0.15·身份/位置 + 0.10·母题回收 + 0.05·状态变化`，权重写死，标注只用于评测。
4. 产出 JSON（2.24 MB，686 步）与报告（48 KB：Top30、A/B 对比、vs 74 标注、重点案例、长度分层、敏感性、复算、局限）。
5. Lead 复核：686 全覆盖、`score=Σ组贡献`（最大浮点偏差 2e-6）、A 的 JSON sha256 未变、两次运行一致。
