# log/ —— 逐步行动记录

> 用途：记录**每一步实际做了什么**（不是计划、不是结论），便于复盘、写报告、交接和排查"某个数字是哪次跑出来的"。
> 与 `docs/method/`（方法说明）和 `docs/stages/`（阶段叙述）的区别：这里是**审计日志**——时间、命令、输入输出文件、验证方式、遇到的问题。

## 记录规范

每个动作一份文件：`NN-<slug>.md`，编号顺序即执行顺序。文件内固定字段：

```markdown
- 时间：
- 目标：
- 实际动作：（按顺序列，写清用什么脚本/命令）
- 输入 / 输出：（文件路径 + 数量）
- 验证：（怎么确认做对了）
- 问题与处置：
- 状态：完成 / 进行中 / 已回滚
```
