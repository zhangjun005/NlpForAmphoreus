# 22 · 角色全程轨迹分析（白厄 / 昔涟）

- **时间**：2026-10-24 20:10–20:40
- **目标**：回答用户质疑——"白厄一开始就出现，你是对全程所有出现都分析了吗，还是只分析了最集中的位置？"

## 实际动作

1. 先做数据核查（Lead）：白厄 2,550 条台词 / 202 个步骤 / 38 个任务 / 7 个版本（缺 3.5）；精读覆盖：刀子场景 21/202、74 标注 25/202、29 关键事件 18/202（约 9–12%）。
2. 派 `baseline-a`（task-21）写可复用脚本 `tools/character_trajectory.py`，对任意角色做全量轨迹分析；
3. 跑 **白厄** 与 **昔涟**，产出 JSON + 报告 + 2 张图。

## 结果：白厄（全量）

| 指标 | 数值 |
|---|---|
| 台词记录 / 步骤 / 任务 | **2,550 / 202 / 38**（67 个任务中的 38 个） |
| 版本分布 | 3.0:634 · 3.1:278 · 3.2:112 · 3.3:649 · 3.4:711 · **3.5 缺席** · 3.6:41 · 3.7:125 |
| 形态（form） | 3.0 出现「幼年形态」9 条；其余多为空（白厄本体） |
| 自称/他称变化 | 3.0 以「老师/黄金裔/开拓者」为主，3.1+ 出现「救世主」他称（同步骤 11 次） |
| 母题 | 「火种」贯穿（3.0 自述 17 / 同步骤 20）；「黎明」「无名」在后期出现 |
| 所在步骤 A/B1 均值 | A −0.011 / **B1 0.106**；Top100 命中 A 10.5% / **B1 19.4%**；中位名次 A 325 / B1 293 |

- **低存在感段**：3.2（112 条）、3.6（41 条）、3.5（0 条）——这些是他台词量最少的版本，也最容易被"集中位置精读"漏掉；
- **精读覆盖率**：21–25 / 202 步（10–12%），所以之前确实是"重点位置精读"，不是全程分析；
- 结论：数据层全量（每句都进语料、每步都打分），解释层是抽样；现在这条轨迹把"全量出场"补上了。

## 结果：昔涟（全量）
