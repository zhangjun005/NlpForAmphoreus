## 八、归一化规则草案（待确认后实现）

两层字段：`canonical_speaker` + `form`。

1. 精确命中 canonical 表 → 归一（`黑塔人偶`→黑塔；`大黑塔`→黑塔 + form）
2. 剥离包装：去成对 `「」『』`、去 `「X爵」` 之类前缀称号、去括号注音
3. 形态词 → canonical + form：
   - 迷迷/德谬歌/往昔的涟漪/PhiLia093 → 昔涟
