## Part C：告别台词的语义回溯（派给 `annotator`，与 Part B 同一任务）

### 想法（用户提出）
3.7 结尾黄金裔们逐一告别时说的话，可能是在**回收前文的特定剧情**。把每个黄金裔的告别台词当作 query，在**更早的剧情**里做语义相似度匹配，找出"最像的剧情片段"——可能揭示"告别词 ← 回收哪一段前文"的对应关系。

### 方法
1. 找到 3.7 结尾的"黄金裔们告别"段（先确认具体 segment，可能包含「黄金裔们：明天见」等群体台词）。
2. 把每位黄金裔的告别台词（或分句）作为 query。
3. 语料 corpus = **该告别段之前**的所有步骤/记录（`segments.jsonl` 按 `order` 截断）。
4. 相似度：TF-IDF（字/词）余弦 + 可选 jieba 词级；取 Top-5 最相似片段。
5. 人工读 Top-5，判断是否真的"回收前文"（语义相似 ≠ 主题回收，必须读原文核对）。
6. 输出：每位黄金裔 → 告别台词 → Top-5 相似前文（segment_id + 文本 + 相似度）→ 人工判断（是/否/存疑 + 理由）。

### 产出
- `data/config/farewell-similarity.json`（query、Top-5、判断）
- `data/reports/knife-scenes.md` 中增加"告别台词回溯"一节（或单独 `data/reports/farewell-recall.md`）

### 预期
- 若多数告别词能匹配到前文对应剧情 → 「告别 = 母题/记忆回收」的量化证据；
- 若匹配多是通用套话 → 说明告别词是独立的仪式化抒情，不承担回收功能。两种结果都可写。
