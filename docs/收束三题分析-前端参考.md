## 一、水晶花寓言：同一个故事被改写了两次

**数据**：三个版本——
- 原版（德谬歌讲的）：#23888–#23900，核心是"碎片里有一团光，而我知道它是『爱』"（#23894–#23896）；
- 昔涟第一改：#23901–#23913，核心是"无瑕＝封闭＝既没有心也不懂爱；破碎是向命运抗争"（#23903–#23913）；
- 终局第二改：#25226–#25230，核心是"光不在花里也不在眼睛里，而在每一片破碎的水晶映照出的世界里"（#25228–#25230）。

**三版本两两相似度（句向量 / 词频加权）**：

| 对比 | 句向量 | 词频加权 |
|---|---|---|
| 原版 vs 第一改 | **0.872** | 0.333 |
| 原版 vs 第二改 | **0.808** | 0.284 |
| 第一改 vs 第二改 | **0.790** | 0.468 |

→ **语义高度相似、词面明显偏离**：三次讲的是同一个故事（句向量 0.79–0.87），但用词换了很多（词频加权只有 0.28–0.47）。这正是"改写"的量化形态：**保住意义、换掉字面**。

**每版最像谁 / 哪条神谕**（句向量）：
- 三版最像的角色都是**昔涟**（0.60 / 0.58 / 0.63），第二改最高（0.63）；
- 三版最像的神谕都是 **O04 遐蝶（0.52–0.54）**，而不是 O13 昔涟（0.46–0.51）——"爱/离别"的语义更贴近 O04，与角色曲《昔涟》的结论一致。

**整段故事作查询**：最像的角色昔涟 0.612，最近邻台词是：
- #26165 昔涟「水晶花之所以美丽，是因为它映出了小妖精的眼睛」（0.745）
- #23833 昔涟「桃子。昔涟。小妖精。喜欢。」（0.650）
- #23918 昔涟「可以让桃子教我呀！什么是『爱』……」（0.621）
- #25239 昔涟「『爱』是一朵清白的花……」（0.607）
- #23984 昔涟「我们的故事，会静静地躺在花丛中……」（0.601）

「水晶花」这个词本身在语料里只出现 **11 次、全部在 3.7、全部由昔涟说**——它是她一个人的词。

## 二、明天见：母题的"承载者"与"语义中心"分离

（已在前文分析，摘要）全库 **23 条**；按谁说：缇宝系 13、白厄 2、遐蝶 2、`generic_npc` 2、莫忒丝 1、旁白 1、开拓者 1、昔涟 1。
- 语义质心最像：**开拓者 0.556** > 昔涟 0.553 > 三月七 0.545 > 缇宝 0.543——缇宝说得最多，却只排第 4；
- 最接近但不含"明天见"的台词，全是昔涟 3.6–3.7 的「明天」段落（#22297 0.709、#26215 0.695、#26237 0.666）；
- 对照「再见面」：只有 2 条，质心最高开拓者 0.627 / 三月七 0.620，最像 O04（0.445）。
→ 结论：**「明天见」是缇宝的母题（说得多）+ 昔涟的语义邻居（想得多）**。

## 三、明天：被讨论的时间，而不是被说出的口号

**计数**：原始匹配 110 条，剔除 2 条"证明天外之界/说明天"的跨词误报 → **108 条**。

**分布**：
- 按说话人：**缇宝 32、昔涟 17、白厄 13**、`generic_npc` 6、旁白 6、遐蝶 5、莫忒丝 5、开拓者 5、丹恒 3、三月七 3；
- 按版本：3.1 **30**、3.7 **28**（两端最高），3.2 12、3.6 10，其余 6–8。

**向量查询**（"明天"作查询）：
- 角色质心：**昔涟 0.4925** > 开拓者 0.4922 > 风堇 0.4873 > 三月七 0.4859 > 缇宝 0.482——这次昔涟排第一；
- 神谕：O11 刻律德菈 0.417 > O10 海瑟音 0.407 > O07 风堇 0.404；
- 最近邻台词：#26201（歌词）、#12615、#10054、#18868、#19509——不再集中在"告别"上。

**与「明天见」的对比**：
| | 明天见 | 明天 |
|---|---|---|
| 条数 | 23 | 108（清洗后） |
| 说得最多 | 缇宝 13 | 缇宝 32 |
| 昔涟 | **1 条** | **17 条** |
| 语义质心 top1 | 开拓者 | **昔涟** |
| 性质 | 仪式性告别语（说给谁听） | 被讨论的时间（在想什么） |

→ 关键结论：**昔涟谈「明天」17 次，却只说 1 次「明天见」**。"明天"是她思考的对象（「至于『明天』何时会到来……」），"明天见"是别人替她说出口的仪式。这和第 5 章"制造明天的人几乎不说那句口号"互相印证。

## 四、能说明 / 不能说明

**能说明**：水晶花三版"语义保留、词面偏离"是改写的量化形态；明天见与明天是两种不同性质的语言（仪式 vs 讨论）；角色曲也是一样（最像昔涟 3.7，但神谕最高是 O04）。

**不能说明**：SBERT 的 0.79–0.87 是"同一主题的高基线"，不能当"逐字继承"；短语查询 0.49 与 0.71 的差值不代表重要性；不能因为最近邻是昔涟就把母题判给她（是"语义邻居"，不是"归属"）。
