# 产物总览（通俗版）：这套分析里都产出了什么

> 目的：让人一眼看懂每个产物的**用途**与**在哪**；顺便回答一个关键问题：**模型不是"每个角色一个"**（见 §3）。
> 数字为 2026-10-24 当前快照；核对清单见 `docs/交付物规格.md` §5。

## 0. 一句话结构

```
语料（原文逐条）
  → 配置/分析结果（谁是谁、哪些算神谕、哪些是刀子/关键事件、标注）
    → 一套共享的向量模型（TF-IDF / LSA / 句向量）
      → 图表 + 每张图配对的"它画的数据"
        → 报告/笔记（AnalysisV2、L3 精读、各专题报告）
```

## 3. 模型层（`data/models/`，不入 git：体积+版权）——**不是每角色一个**

**只有 1 套共享的向量空间**，所有角色、所有台词、所有新文本都映射到同一套空间里：

| 模型/文件 | 是什么 | 怎么用 |
|---|---|---|
| `vec_rec.joblib` | **词面模型**（TF-IDF，记录级 11,737 维；带自定义分词） | 把任意文本变成"词频向量"，可算词面相似度 |
| `vec_word.joblib` / `vec_char.joblib` | 步骤级词 TF-IDF / 字符 n-gram TF-IDF | 步骤级检索、A/B 检测器用 |
| `svd_seg.joblib` / `svd_rec.joblib` + `Z_seg.npy` / `Z_rec.npy` | **降维模型**（LSA，100 维） | 压缩后的语义向量，做聚类/检索 |
| `Z_sbert_rec.npy`（26,332×512）/ `Z_sbert_seg.npy`（686×512） | **句向量模型输出**（bge-small-zh-v1.5，语义向量） | 语义相似度、神谕曲线、歌词查询 |
| `data/models/sbert_model/`（91.8 MB） | **句向量模型本体**（本地化，断网可用） | 给新文本编码（歌词） |
| `X_word.npz` / `X_char.npz`、`S_*.npy`、`ids.json`、`manifest*.json` | 矩阵、相似度矩阵、行号对齐表、产出清单 | 复算/查对齐 |
| `feat_A/B.npy` | 检测器特征矩阵 | 复现 A/B 分数 |
| `character_centroids.npz`（394.8 KB） | **角色向量**：14 个角色各自的向量质心（SBERT+TF-IDF），另含按版本质心，共 124 个向量 | 做「角色 vs 歌词」「角色 vs 角色」的整体相似度；`encode_text.py --char` 的质心比对就用它 |
| `data/config/character-centroids.json` | 上述角色向量的说明与每版本条数 | 查"某角色各版本有多少台词、质心在哪" |

**角色向量怎么来的**：先有"每条台词"的向量（26,332 条），把某个角色的所有台词向量取平均、再归一化，就得到这个角色的**一个向量**（质心）；按版本分别平均，就得到"每版本的角色向量"（可看角色语言随时间漂移）。

**关键澄清**：没有"白厄模型""昔涟模型"。所谓"每个角色的分析"是同一套模型算出来的**派生结果**：
- 每人一条**轨迹表**（统计：说多少、怎么称呼、什么形态）；
- 每人一条**神谕相似度曲线**（把该角色的台词按步骤聚合成向量，再和神谕比）；
- 每人一份**上下文表**（`data/context/`，台词+前后文）；
- 每人一份**L3 精读笔记**（`data/reports/l3/`，人读文本后的解释）。
> 若想"每个角色一个模型"（如分类器），现在没有做，也没必要——报告要的是语言解释，不是分类精度。

## 4. 图与"它画的数据"（入 git：图与索引；`plot_data` 本地）

- `docs/report/figures/`：**29 张图**（f1–f15 + `oracle_sim/` 14 条角色曲线 + 新增三张报告图）；
- `data/plot_data/`：**29 份 CSV + 29 份 meta**——每张图"画什么就存什么"，meta 里有轴定义/来源/生成脚本/sha256；
- `docs/report/figures-index.md`：图 ↔ 数据 ↔ 脚本 ↔ 来源 的一页索引；
- **换样式**：只改画图代码、用同一份 CSV 重画，比对 sha256 即可确认数据没变。

## 6. 我想让你记住的三件事

1. **模型只有一套**（词面 + 降维 + 句向量），角色分析是"同一模型 + 不同筛选"的派生结果；
2. **每个数字都能回到原文**：图 → `plot_data` CSV → 配置/矩阵 → record_id → `amphoreus.final.jsonl`；
3. **所有 L3 驱动的修正都登记**在 `data/config/l3-open-questions.json`（21 条），改了什么、为什么改、还剩什么未决，一页可查。
