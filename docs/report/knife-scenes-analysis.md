## 1. 结论（可直接抄进报告）

1. **B1 明显比 A 更能抓住人类认定的「刀子/高光」**：场景级最好名次的中位数 A = **116**、B1 = **57**；Top100 覆盖 A = **13/35 = 37.1%**、B1 = **25/35 = 71.4%**（Top20：A 1/35 = 2.9%、B1 5/35 = 14.3%；Top50：A 5/35 = 14.3%、B1 14/35 = 40.0%）。
2. **但仍远未「抓住」**：即使 B1，也只有 **25/35 = 71.4%** 的刀子场景进入 Top100——人类验证集里约 1/4 的高光，两个检测器都排不进去（双漏 9 个）。
3. **高于随机，但 A 的优势有限**：随机抽同样多步的期望覆盖为 Top20 1.10 个 / Top50 2.75 个 / Top100 5.48 个（率 3.2% / 7.9% / 15.7%）；A 的 Top20 命中（1/35 = 2.9%）只相当于随机，Top100（13/35 = 37.1%）约为随机 2.4 倍；B1 分别约为随机 4.5 / 5.1 / 4.6 倍。
4. **比「人工显著性标注」更集中**：同为 segment 级，刀子场景的 Top100 覆盖 A 13/36 = 36.1%、B1 23/36 = 63.9%；而 74 条标注里等级 ≥2 的 28 条显著样本，Top100 覆盖只有 A 7/28 = 25.0%、B1 13/28 = 46.4%。→ 人类「高光/刀子」比「一般显著」更容易被检测器抓到（这也说明刀子是更极端的样本），两类标注不能互相替代。
5. **B1 的提升集中在「结构性强」的场景，对「纯对话/情感错位」反而扣分**：提升最大 K23（+277）、K26（+247）、K27（+247）；提升最小/变差 K18（-154）、K03（-83）；双漏 9 个场景全部是长段告别/独白/群像诗（见 §5），词面与结构特征都无处落脚。

### K03 · 「悬锋王朝，于此终结」——万敌告别阿格莱雅 ｜ 万敌

- 最好名次：A 第 **225** 名、B1 第 **308** 名（B1 变化 -83）。
- 原文摘录：
  > [narration] 你决绝地否定了悬锋人千载的荣耀执念，决定独自还乡，接下尼卡多利抗击黑潮的使命。在迈上回乡之路之前，你还需与城中的友人们一一作别。
  > [万敌] 出发前，还有些人要见。
  > [阿格莱雅] 你来了，迈德漠斯……
- 为什么难：「悬锋王朝，于此终结」——万敌与阿格莱雅的告别：两人用礼貌、克制的中文对白互相托付，最重的一句是「再见了，万敌」。全段只有「背后负创而死」一句是强词面，却被大段日常对白稀释；B1 的结构项还把它从 225 推到 308（越结构化越像「普通对话」）。

## 6. 交叉表：刀子里有多少是神谕兑现 / 标注等级 3

| 场景 \ 标注等级 | 等级3 | 等级2 | 等级1 | 等级0 | 未标注 |
| --- | --- | --- | --- | --- | --- |
| 神谕兑现 | 3 | 0 | 0 | 0 | 11 |
| 非兑现 | 6 | 3 | 1 | 0 | 11 |

- 35 个刀子场景中，**14 个**场景落在神谕兑现段上，覆盖了 13 条 gold 中的 **13 条**（O01、O02、O03、O04、O05、O06、O07、O08、O09、O10、O11、O12、O13；K26/K27 共用 O13 同一兑现段）（K01、K05、K08、K09、K11、K12、K15、K17、K19、K20、K21、K22、K26、K27）；**9 个**被人工标注为等级 3（K02、K14、K17、K25、K26、K27、K30、K32、K33）；两者都满足的只有 **3 个**（K17、K26、K27）。
- 即「刀子 ≠ 神谕兑现」：14/35 的刀子是神谕兑现，另外 21 个高光（告别、群像、牺牲等）不在 13 条 gold 里；人类验证集因此补足了「非神谕兑现的高光」这一类样本，也解释了为什么这批样本更难被现有词面方法抓到。

## 7. 局限

1. **场景级「最好名次」天然乐观**：35 场景中 3 个跨 2 步，取最好名次相当于给场景 2 次机会；与标注样本对比时已改用 segment 级（§3）。
2. **场景是人工从原文里「抽」出来的**，选点时可能受「哪段更好读/更有冲击」影响，带选择偏差；且 A/B1 的 rank 是既有的固定结果，本分析没有重新训练/调权重。
3. **双漏的解释是定性的**（逐条读原文后的判断），不是特征归因；要定量归因需做消融。
4. **样本量**：35 场景 / 36 个唯一 segment，覆盖率的分母很小（1 个场景 = 2.9 个百分点）；与 28 条标注样本的对比也只是描述性，不做显著性检验。

## 8. 复现

```bash
conda run -n nlpLesson python tools/knife_scene_eval.py
conda run -n nlpLesson python tools/knife_scene_eval.py --verify
```

- 无随机：映射、覆盖率、随机期望都是解析计算；图由 JSON 同源数据绘制。
- `data/config/knife-scene-scores.json` 保存 35 场景的映射、A/B1 排名、指标、随机期望、双漏清单与交叉表；报告数字与之同源。
- `--verify` 会重算映射与最好名次、重算覆盖率/交叉表，并抽查报告中的 3 个数字。
