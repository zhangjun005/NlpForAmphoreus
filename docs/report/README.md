## 一句话论点（建议作为报告结论）

**翁法罗斯的"命定"不是抽象概念，而是可测量的语言形式：神谕拥有一套显著独特的语体（文言、情态词、第二人称、抽象名词），角色在引用它时整体向该语体靠拢、但改写时偏离；而叙事的"转折深度"无法只靠词面情绪检测，需要身份变化、母题回收、语义突变等结构信号。**

## 关键结论清单（可直接抄）

1. **神谕语体显著独特**：文言虚词率 9.02（神谕）/ 0.99（对白），Cliff δ=0.91；情态词 δ=0.83；抽象名词 δ=0.65；第二人称 δ=0.59（全部 Bonferroni 显著）。句长不显著（δ=0.28, n.s.）。
2. **引用语体整体向神谕靠拢**：G3 引用 vs G1 神谕 13 个特征中仅第二人称显著（δ=0.51, p=0.003），其余无显著差异；G3 vs G2 对白在文言/情态/抽象/句长上显著 → 引用句显著"神谕化"；PCA 质心距离 G1–G3=1.13 < G2–G3=2.05。
3. **但"靠拢"主要来自字面照搬**：34 处引用中 31 处保留原句；改写型（C 型，3 处）文言率降到 2.03（完整引用 7.33）、情态 1.15（6.07）→ **改写即偏离**，这是一个可写进报告的反差。
4. **话题匹配后语体差异仍在**：G1 vs G2 的文言/情态/第二人称差异在"涉及死亡/命运/终结/记忆"的句子里仍显著（δ +0.92/+0.91/+0.79）→ 不是题材造成的。
5. **引用轨迹**：阶段分布 = 结局宣告 8 / 他人解释 7 / 原文出现 6 / 本人引用 5 / 旁白 4 / 改写反转 3 / 主动认领 1；引用者 = 本人 19 / 他人 10 / 旁白 4。趋势"旁白/他人 → 本人认领/宣告"方向一致但只是**弱趋势**（剔除步差 0 后只剩 8 条弧线，不做统计推断）。
6. **镜像对 O10/O11**：同词异序（分句互换、均 21 字）；O11 唯一出现处由**海瑟音**说出，刻律德菈本人从未引用任何神谕；兑现层面出现"分句交叉"——这是 O10 判反转、O11 判错位的文本依据。
7. **词面基线判不了转折深度**：A（词面+局部情绪）与 74 条标注 Spearman=0.401，等级 1/2/3 的分数几乎持平（0.20/0.22/0.23）；74 条中显著样本（≥2）在 A 的 Top100 只覆盖 7/28。
8. **结构增强打开了深度维度**：B1 Spearman=0.581，等级 0/1/2/3 = −0.68/0.16/0.28/0.70；显著样本 Top100 7→13；神谕兑现段 Top100 5→11、中位排名 106→53。
9. **B 的边界**：长度偏差比 A 更强（ρ 0.438→0.683），增益集中在 >30 句层；短步修复尝试 B2 为**负结果**（Spearman 0.541 < 0.581），说明短步需要新信号（句向量/句子级显著性），不是调权重。
10. **类型与显著性**：B 提升最大是 prophecy（+168，但由单样本 `3.7|魔女|21` 273→26 带动）、sacrifice 组内一致性最好（ρ=0.82）；**world 反而变差**（−17）。神谕兑现段显著高于其他步（A δ=0.635, p=8.7e-5；B1 δ=0.844, p=1.8e-7），>30 句层内仍显著；**但兑现段多含神谕原文（词面构造成分），不能当显著性标签**。
11. **检索**：v1 关键词基线 MRR 0.731 最高，但 12/13 条 gold 就是吟诵步 → 退化为"引用句匹配"；v2 掩蔽/剔除吟诵步后 12/13 条 gold 被删、只剩 O10，**现有 gold 上无法做方法对比**（O10 在剔除吟诵步后由第 7 → 第 3 名，是唯一方向性证据）。
12. **数据规模**：26,332 条 / 566,798 字 / 67 个任务页 / 8 个版本（3.0–3.7）/ 归一 97.58% / 文本纯度 0 残留。
