## 1. 方法链路（每个点怎么来的）

1. **记录**：`amphoreus.final.jsonl` 中 `canonical_speaker == 角色` 的记录（记录 id 与 `ids.json` 对齐，共 26332 条）。
2. **向量**（复用 `data/models/`，未重新训练）：
   - 词频加权：`vec_rec.joblib`（analyzer=tokenize, ngram=(1,2), min_df=2, sublinear_tf）对 `text_clean` 做映射（11737 维）；
   - 语义向量：`Z_sbert_rec.npy`（bge-small-zh-v1.5，512 维，已 L2 归一）按记录 id 取行。
3. **步骤聚合**：按 `(version, task, step_idx)` 分组，取该角色台词的**均值向量**（词频加权 行均值后再归一；语义向量 行均值后再归一），同时保存「记录级最大值」`*_own_max`、台词条数 `n_lines`、记录 id 列表 `record_ids`（可回查）。
4. **神谕向量**：`vec_rec.transform(13 条神谕原文)`（词频加权）；语义向量 用同一模型现场编码 13 条神谕（`normalize_embeddings=True`），两条向量都保存在 JSON 的 `oracle_vectors` 里。
5. **余弦**：`cos(步骤均值向量, 自己神谕向量)`；同时保存与**全部 13 条神谕**的相似度向量。
6. **平滑**：原始值 + 居中滚动均值（窗口 5 步，基于该角色自己的出场步骤序列）。
7. **时间轴**：`order`（3.0→3.7）；版本边界：3.0@1、3.1@11、3.2@20、3.3@30、3.4@39、3.5@45、3.6@52、3.7@61。

**own oracle 映射**：白厄→O09；万敌→O03；阿格莱雅→O01；缇宝→O02；遐蝶→O04；那刻夏→O06；风堇→O07；赛飞儿→O08；海瑟音→O10；刻律德菈→O11；昔涟→O13；开拓者→无；三月七→无；丹恒→O12；开拓者与三月七没有自己的神谕 → 曲线取「与 13 条神谕的最高相似度」；丹恒承接大地火种 → own = O12（大地线）。

**数据一致性**：记录级 词频加权 相似度与已有 `S_oracle_rec.npy`（13×26332）最大绝对差 = **0.0**；总记录 26332 / 总步骤 1802。

## 5. 局限

1. **词频加权 是词面相似**：会因共享「汝将/涛声/火种」等词而高，不代表语义读懂；语义向量 是句子级语义，但仍非「含义强度」，两者都不能直接当作「角色理解了神谕」的证据。
2. **3.5 嵌套闪回**：3.5 版本内有大量回放/嵌套叙事（如 O10/O11 的镜像段），order 是全局顺序，闪回内容会与当前时间线错位；曲线在 3.5 附近的峰可能只是「在复述过去」，不是「当下剧情」的峰。
3. **稀疏角色样本量小**：刻律德菈 31 步、海瑟音 45 步（A 组）与三月七 53 步（B 组），滚动均值与峰值的稳定性有限；荒笛（NPC，70 条 / 4 步）只在丹恒条目内说明、不单列曲线。
4. **B 组 own oracle 口径不同**：开拓者/三月七没有自己的神谕，曲线取「与 13 条神谕的最高相似度」，与黄金裔的 own-oracle 曲线不可直接比大小；丹恒 own=O12 为大地承接设定。
5. 步骤均值向量丢失了步内分布；`*_own_max`（记录级最大）保留了上界信息，可对照看。

## 6. 复现与自校验

```bash
conda run -n nlpLesson python tools/oracle_similarity_curves.py
conda run -n nlpLesson python tools/oracle_similarity_curves.py --verify
```

- 无随机：向量资产复用、模型推理 deterministic；`--verify` 从 JSON 抽查 5 个点重算 step 均值向量余弦。
- JSON 保存每步的 `record_ids`、`record_id_span`、13 神谕相似度向量、神谕向量（词频加权 稀疏项 + 语义向量 512 维），任何点可按「记录 id → 向量 → 均值 → 余弦」复算。
