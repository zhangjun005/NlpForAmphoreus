## 图 13 「水晶花寓言」语义曲线

**标题建议**：K36「水晶花寓言」与 686 步的相似度：原始 TF-IDF 单点最高，平滑曲线在 3.7 末段整体抬升

**图注（可直接用）**：
本图把 686 个候选步骤分别与「K36 水晶花寓言」的参考文本（K36 的标题 + 人工判读 `why`）计算相似度：细线为原始值、粗线为滚动均值 25，左轴 TF-IDF、右轴 SBERT。K36 所在的步骤 `3.7|魔女的孤诣课题|21`（order=63）在原始 TF-IDF 上为 **0.180430，排 686 步第 1**；原始 SBERT 为 0.613717（第 13/686）。但这是**步骤级**结果：该步骤包含 484 条记录（#23576–#24065，同时含 K26、K27 与 K36），且参考文本本身就是对 K36 的人工摘要——所以这个最高值含有「自我匹配」，不能当作独立发现。平滑后，K36 位置只是 3.7 末段抬升中的一个台阶（TF-IDF 滚动 0.0237、SBERT 滚动 0.4990），两条平滑曲线的最高点都在 3.7 结尾（TF-IDF 0.0331 @ `3.7|银辇|13`；SBERT 0.5487 @ `3.7|落英|13`）。图支持的判断应限定为：**3.7 结尾（创世诗/昔涟回望，如 `3.7|纸页|11` TF-IDF 0.1787、`3.7|落英|11` 0.1303）与 K36 有真实的词汇/主题重叠；K36 本身不是平滑曲线上的峰。**

**对应原文（可核对）**：
- K36 原文：#23885「记忆的花」：「我还会讲故事。会讲故事才是「昔涟」。」… #23902–#23907 改写「无瑕即无爱」… #23910「水晶花掉在地上，碎掉了。」→ #23913「而在它眼里，不再「无瑕」的水晶花，终于有了「心」，也学会了「爱」。」（record 区间 #23885–#23913，29 条）
- 同步骤的相关段落：K26 #23576–#23595（诞生地/德谬歌）、K27 #23928–#23984（「哀怜/爱」与收梢宣告）
- 3.7 词面高点：`3.7|纸页|11`（#25204–#25257 创世诗）、`3.7|落英|11`（#26115–#26199 昔涟收束独白）
- 3.5 闪回高点（SBERT 高、TF-IDF≈0）：`3.5|流年|2`（0.5721）、`3.5|花醴|18`（0.5622）、`3.5|归风|2`（0.5584）、`3.5|初日|17`（0.5439）、`3.5|大海|13`（0.5428）

**支持判断**：3.7 结尾与 K36 的主题（爱/心/破碎/故事/收梢）确实呼应；但「相似度」不等于「含义强度」，且步骤级曲线不能定位到 K36 的 29 条记录。
**局限**：① **参考文本循环**：参考=K36 自己的标题+`why`（task-25 标注文本），K36 步骤必然高分；② **步骤≠K36**：`魔女|21` 一步 484 条，K36 只占 29 条（#23885–#23913），峰不能归给 K36 单独；③ **x 轴 order 是任务页序号**（67 个 order，一步最多 30 条），同一 x 上多步竖直堆叠，图上的「竖刺」不是连续时间序列；④ **3.5 闪回假峰**：3.5 的高 SBERT 点（流年/花醴/归风/初日/大海）是海瑟音/刻律德菈/昔涟的回忆段，TF-IDF 多为 0 或 <0.05，说明 SBERT 捕捉的是「爱/梦/离别/故事」的主题相似，不是 K36 的原文回收；另 `3.1|谧林|19/20`（0.628/0.633）与 `3.6|大墓|24`（0.6199）也属此类语义假峰。
**两线为何不同**：TF-IDF 是精确词袋，只有字面出现「水晶花/无瑕/心/爱/破碎/故事/讲述者/收梢」等词才抬升（大量步骤=0，稀疏、特异但脆）；SBERT 是句向量语义，所有叙事段普遍 0.45–0.55 的基线，能捕捉主题但把「同一主题」「同一情感浓度」都算作相似，因此假峰多、特异性低；两轴量纲也不同（左 0–0.18、右 0.25–0.65），高度不可直接比较。

**核验结果**：686 行与 CSV/原文一致；K36 段定位、原始值 0.180430/0.613717 与 CSV 完全一致。**但「K36 附近抬升」只对原始 TF-IDF 单点成立，平滑曲线不成立**——见下方「建议修正」。

## 图 14 O10/O11 镜像对

**标题建议**：O10/O11 镜像对：同一词袋的 TF-IDF 完全重合，SBERT 仅微小差异（#20228/#20229 位于同一段）

**图注（可直接用）**：
本图把 686 步分别与两条镜像神谕计算相似度：O10 =「汝将长眠于涛声中，于天地境界之海完成征服。」（海瑟音），O11 =「汝将于天地境界之海完成征服，长眠于涛声中。」（刻律德菈）。两条神谕的**词袋完全相同、只是语序互换**，因此左图（TF-IDF）两条曲线在全部 686 行上**逐点相等、完全重合**——这不是绘图错误，而是「词面相似度对词序不敏感」的直接结果。右图（SBERT）两条曲线也只有微小差异：平均绝对差 0.0053、最大 0.0180；614/686 行 O11 略高于 O10，形成一条几乎贴合的虚线。原文中的关键位置是同一段：`3.5|囚人啊，踏过日影见沧溟|15`（order=51）里 #20228 与 #20229 相邻，海瑟音先念 O11 语序、再念 O10 语序；同 order 的 `囚人|5` 有旁白 #20145 把两种语序连念。图支持的判断是：**词面相似既不能区分镜像对、也不能判定「兑现」*——TF-IDF 峰值出现在吟诵/复述段（`囚人|5` 0.499、`囚人|15` 0.174），而 O10 的兑现段 `3.5|大海|14`（#19814 海瑟音献出余生的清醒与自由）TF-IDF 仅 0.0187，接近地板。

**对应原文（可核对）**：
- #20145 旁白（`3.5|囚人|5`）：「于天地境界之海完成征服，长眠于涛声中。长眠于涛声中，于天地境界之海完成征服。…」（两种语序连念）
- #20228 海瑟音（`3.5|囚人|15`）：「汝将于天地境界之海完成征服，长眠于涛声中——」（= O11 语序；引用编码：O11 他人解释 + O10 改写反转双列）
- #20229 海瑟音（同段）：「汝将长眠于涛声中，于天地境界之海完成征服——」（= O10 语序；引用编码：O10 本人引用）
- #19814 海瑟音的记忆（`3.5|大海|14`）：「海洋啊！我向你献上余生的清醒和自由——…」（O10 的兑现事件段，反转）
- #20339 旁白（`3.5|囚人|15`）：「在这预言中的『天地境界之海』，一汪浅浅的死水里，凯撒在思考什么呢？…」（O11 的兑现事件段，错位——与 O11 的引用同段，无法在步骤级分离）

**支持判断**：「词面相似 ≠ 兑现」有两个证据：① O10/O11 的 TF-IDF 曲线 686/686 行完全相等→词面无法区分哪条神谕；② 词面峰值在吟诵段（0.499）而非兑现段（0.019）；③ SBERT 差异虽在关键点方向正确（O11 兑现段 O11 高 0.0094、O10 兑现段 O10 高 0.0045），但幅度小于无关段的噪声差（如 `3.0|银辇|3` 差 0.0172、`3.4|回返|3` 差 0.0180），不能作判别。
**局限**：① 图同样是步骤级、x=order 重复（竖刺）；② 两条神谕的引用都在同一段（order 51），图上只有一个峰，**不存在「两条曲线交错」**——交错的观感来自 SBERT 虚线与实线的极小高低差；③ O11 的「兑现」与「引用」同段（`囚人|15`），步骤级无法把「兑现」从「吟诵」里剥出来；④ v2 的 O10 吟诵段（`囚人|5`、`囚人|15`）与 O10 兑现段（`大海|14`）是不同段，但 O11 的吟诵与兑现同段——两 oracle 不可用同一套「吟诵 vs 兑现」口径对比。

**核验结果**：686 行与 CSV/编码一致；#20228/#20229 同段定位正确；TF-IDF 全等（686/686 行）与 SBERT 差异统计可复算。**「两条曲线交错」的表述不准确**，应改为「TF-IDF 完全重合、SBERT 仅微小差异」。
