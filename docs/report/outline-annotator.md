## 0. 中心论点（一句话）

> **翁法罗斯的「命定」不是预言写好的事件清单，而是一套被写成固定文体、由角色反复转述—认领—改写、并在旧记忆与旧意象的回收中完成意义翻转的语言机制；因此真正制造叙事转折的，不是「死亡/牺牲」这类强烈词汇，而是「前文被重新解释」的那一刻。**

这句话对应 `方向与理由v2.md` §七 的最终形态（命定存在于语言形式、引用与回收中；冲击来自长期铺垫后的身份变化/关系反转/意义重构），但把「文本生命周期」与「叙事显著性」两条线收束成一个可被剧情证明的判断：**命定是被说出来的、被角色接管的、被回收改写的**。

一句话之外的展开（用于摘要/结论）：

1. **文本层**：神谕有一套可测量的独特文体（文言虚词、情态词、第二人称「汝」、抽象名词）；角色引用它时向它靠拢，改写时偏离。
2. **行为层**：引用者从旁白/他人转述逐渐转向本人认领与结局宣告；镜像对 O10/O11 甚至把「谁在替谁念神谕」变成叙事装置。
3. **回收层**：3.7 的告别与「明天见」把散落 3.0–3.6 的母题重新点亮；昔涟的「收梢」让终结成为起始，完成「命定如何被写定、又被改写」的闭环。
4. **方法层（边界）**：上述三点不能用「死亡词/情绪词」检测出来；A（词面基线）在人工等级 1/2/3 上几乎持平，B（结构增强）才能拉开深度，但仍会漏掉约 1/4 的人类高光。

## 1. 写作原则（必须先定，否则又会写成统计报告）

1. **证据分层，正文只放前两层**：
   - 第 1 层：**原文与 record_id**（正文引用，读者可核对）；
   - 第 2 层：**人工判读**（含义 before→after、引用阶段、兑现类型——来自 `key-events.json` / `oracle-citation-coding.json` / `oracle-fulfillment.filled.json`）；
   - 第 3 层：**统计量（Spearman / Top-k / MRR / δ）**——只放章节末尾或附录，作为「这个判断不是孤例」的支持；
   - 第 4 层：**方法细节**（特征表、权重、复现命令）——一律进附录。
2. **每章开头 300–600 字必须是一个剧情场景**，不许以数字或方法名开头；统计图表出现在该章后半。
3. **术语纪律**：正文用「叙事显著性/叙事转折点」，不用「读者情绪/催泪度」；TF-IDF 的轴只能叫「词面相关性」，不能叫「含义强度」；「吟诵神谕的步骤」≠「神谕兑现事件」。
4. **诚实声明前置**（导论末尾或方法附录开头）：74 条标注是**固定规则下的 LLM 辅助标注**，一致率是**重复标注稳定性**而非与人类 gold 的一致率；不宣称测量读者真实情绪。
5. **角色口径（task-25 用户最终裁定，全文统一）**：黄金裔 = **11 位**（白厄、万敌、阿格莱雅、缇宝、遐蝶、那刻夏、风堇、赛飞儿、海瑟音、刻律德菈、昔涟）；游戏称「十二黄金裔」，但「岁月」席位历史上多次更换（欧洛尼斯一线／德谬歌与昔涟的演化），实际固定为 11 位。**荒笛、玻吕茜亚 = NPC 类**（荒笛 70 条/4 步，大地承接：荒笛 → 丹恒；玻吕茜亚 72 条/5 步，O05 为双子共有神谕 holder=玻吕茜亚）；**开拓者、三月七、丹恒 = 单列分析**（3 人，不纳入黄金裔比较；三月七 664 条/53 步，形态 长夜月/永夜之帷/幻象/记忆形态）。写作与图表按此口径，引用原文时保留游戏内称法。

## 2. 章节大纲（7 章 + 附录）

### 第 1 章 导论：从「命定」到「语言」（建议 800–1200 字）

- **本章论点**：翁法罗斯把「命运」写成可以被复诵、被引用、被改写的文本；因此可以用 NLP 研究它「如何被写定 / 如何被接管 / 如何被回收」，而不是研究「预言是否灵验」。
- **剧情案例**（先讲场景再给问题）：
  - 开场用 **O09 的完整链路**做全文缩影：3.4 白厄梦见神谕（`#15680` 旁白）→ 3.4 白厄把「救世主」之名交给开拓者（`#16719`）→ 3.7 揭示这条神谕其实是昔涟写下的（`3.7|落英啊，残芳纷飞留归躅|7`，`#26045`）。三步之内，「神的预言」变成「一个人写给另一个人的希望」——这正是全文要解释的语言事件。
  - 收束预告：3.7 结尾缇宝说「明天见」、白厄说「明天见，乘以一千」（`#25778`、`#25779`），「明天见」从 3.1 妈妈临终的一句话（`#6876`）变成全篇的预言。
- **数据/证据**：`docs/report/data-tables.md` §1（26,332 条 / 566,798 字 / 67 任务页 / 8 版本 / 说话人归一 97.58%）；`data/corpus/oracles.jsonl`（13 条神谕）、`data/corpus/ruby-pairs.jsonl`（1,020 对注音）；「明天见」在语料中出现 23 次。
- **写作要点**：① 作品背景只写与「命定/记忆/轮回」相关的部分，不写成剧情简介；② 把三个研究问题（Q1 文体、Q2 引用与接管、Q3 显著性能否只靠词面）落在这一章末尾；③ 明确「本文不判断哪条神谕更感人，只判断文本如何改变意义」。
- **缺口**：无。

### 第 2 章 命定如何被写成语言：神谕文体与隐喻解码（建议 1500–2000 字）

- **本章论点**：神谕的力量首先来自**可辨识的文体**：它用文言虚词、「汝/将/必/终」情态、第二人称与抽象名词，把一句内容普通的话写成「命定」；角色引用时整体向这个文体靠拢，但**改写时明显偏离**。
- **剧情案例**：
  - 文体样本：O09「汝将肩负骄阳，直至灰白的黎明显著。」（`#16719`）、O01「汝将最后一次沐浴，在温热耀眼的黄金中。」（`#7458`）、O10/O11 两条 21 字镜像句（`#20228`/`#20229`）。
  - 隐喻解码：O09 的注音释义——「汝」=白厄、「黎明」=天外的救世主、「灰白的黎明」=开拓者（见 `data/config/oracle-fulfillment.filled.json` O09.metaphors）；说明「预言的字面」与「角色的真实所指」从一开始就错开。
  - 引用 vs 改写：O01 第三次出现是「**我将**最后一次沐浴…——现在，是时候将其兑现了」（`#16615`），人称从「汝」改成「我」；神谕的「预言体」被改写成「第一人称的宣言」。
- **数据/表/图证据**：`data-tables.md` §4（G1 神谕 / G2 对白 / G3 引用 的 13 特征表）+ **F3** `figures/f3_style_features.png`；`data/reports/style-compare.md` §1 四条结论（文言虚词 δ=0.91、情态 δ=0.83、抽象名词 δ=0.65、第二人称 δ=0.59，均显著；句长不显著）；
  G3 分型：34 处引用中 29 完整引用 / 2 片段 / 3 改写；改写型文言率跌到 2.03（完整引用型 7.33）——**「靠拢来自照搬、改写即偏离」**。
- **写作要点**：① 先让读者看三组真实句子（各 1–2 句），再上 δ；② 「神谕体」不是玄学，而是 4 个可数特征的组合；③ 指出「引用＝向神谕语体靠拢、改写＝偏离」这一反差是全文第一个可验证的结论；④ F3 只作旁证，不要把 13 行特征表搬进正文。
- **缺口**：G1/G3 样本很小（14 / 48 句），正文必须写「方向性比较，不做强结论」。

### 第 3 章 命定如何被角色接管：引用轨迹与话语角色（建议 1800–2400 字）

- **本章论点**：神谕的权威不是固定属性；它随着「谁在说、对谁说、说到哪一步」而转移——引用者从旁白/他人转述，逐渐转向本人认领与结局宣告；角色不是被动承受预言，而是在引用中把预言变成自己的话。
- **剧情案例**（按「说的方式」组织，不按神谕编号平铺）：
  1. **本人第一次说出**：阿格莱雅对万敌自述「汝将最后一次沐浴…」（`3.1|王座啊，终了那数载索寞|2`，`#7458`），万敌回「果然是不知所谓的末日预告」，阿格莱雅却笑「我戒不掉沐浴带来的宽畅享受」——**接受预言就是接受自己的死法**。
  2. **他人替你说**：O11 是刻律德菈的神谕，但全篇唯一出现处是**海瑟音**之口（`3.5|囚人啊，踏过日影见沧溟|15`，`#20228`）；海瑟音紧接着又念出自己的词序（`#20229`），并评点「预言如海蛇首尾相衔」（`#20230`）。刻律德菈本人从未引用任何神谕——**镜像对的话语权是单向的**。
  3. **敌人也背得出**：3.4 的白发剑士（卡厄斯兰那）当着缇宝背出 O02 原句（`3.4|英雄啊，点燃那最初的骄阳|6`，`#17080`），缇宝反应「怎么可能……」——神谕可被敌人掌握，本身就是叙事压力。
  4. **结局宣告/改写**：O01 阿格莱雅在记忆里宣告「是时候将其兑现了」（`#16615`）；O04 遐蝶「为它写下另一种诠释」（`#11467`）；O09 白厄把「救世主」之名转交（`#16719`）。
- **数据/表/图证据**：`data/reports/oracle-citation-timeline.md` §1（阶段分布：结局宣告 8 / 他人解释 7 / 原文出现 6 / 本人引用 5 / 旁白转述 4 / 改写反转 3 / 主动认领 1；引用者：本人 19 / 他人 10 / 旁白 4 / 敌人 1）+ **F4** `figures/f4_citation_stage.png`；`data/config/oracle-citation-coding.json`；
  「首次→末次」弱趋势：13 条神谕首次引用时本人 5/13、末次引用时本人 8/13、结局宣告 7/13——但剔除 5 条「步差 0」后只剩 8 条弧线，**只能写成弱趋势**。
- **写作要点**：① 这一章最好看，应写成「谁在替谁念神谕」的故事，而不是阶段分布表；② 镜像对 O10/O11 单列 300–500 字（同词异序、单向转述、分句交叉兑现：刻律德菈对应「长眠于涛声中」，海瑟音对应「天地境界之海」）；③ 统计表放章末，明确 34 处是小样本；④ 提醒读者「吟诵位置≠兑现位置」，为第 4 章铺垫。
- **缺口**：A1（吟诵段/事件段拆分）未确认，本章的「位置」只能按语料顺序讲；3.5 的嵌套闪回导致 O10 的「兑现段」在语料顺序上早于引用段 8 步，正文要注明。

### 第 4 章 命定如何被兑现：13 条神谕的意义履历（建议 1800–2400 字）

- **本章论点**：兑现不是「预言应验」这么简单，而是三种关系——**字面、反转、错位**；而真正的意义变化发生在角色对预言的重新解释里（预言被改写、被转交、被揭示为人造）。
- **剧情案例**（挑 6 条精讲，其余进附表）：
  1. **O01 阿格莱雅（字面→主动完成）**：`#7458` 自述 → `#16615`「是时候将其兑现了」→ `3.3|金丝|7` 遗书说明她如何设计自己的死（`#12683`–`#12703`）。

  3. **O09 白厄（全篇最重要的个案，300–500 字）**：`#15680` 梦见神谕 → `#16719` 把「救世主」之名交给开拓者 → `3.7|落英|7` `#26045` 揭示这条神谕是昔涟为给他希望而写。**神谕从「神的命令」变成「一个人写给另一个人的语言」**——正好回扣第 1 章的缩影。
  4. **O10/O11 海瑟音/刻律德菈（镜像 + 交叉兑现）**：`3.5|囚人|5` 旁白并置（`#20145`）→ `#20228/#20229` 海瑟音连念两种词序 → 刻律德菈死于「预言中的天地境界之海，一汪浅浅的死水」（`#20339`）→ 海瑟音献出清醒长眠涛声（`#19814`）。判 O10 反转、O11 错位。

### 第 5 章 叙事显著性不等于刀子：关键事件与检测器的边界（建议 2000–2600 字）

- **本章论点**：文本冲击来自「含义变化」（旧解释被新解释覆盖），不是「出现死亡/牺牲词」；因此 A（词面）在人工等级 1/2/3 上几乎持平，B（结构增强）才能拉开深度维度——但 B 仍会漏掉约 1/4 的人类高光，且对「纯对话告别」反而扣分。
- **剧情案例**（先讲失败/反例，再讲统计）：
  1. **最重的道别被排到 308 名**：万敌与阿格莱雅的告别（`3.1|王座|2`，K03）A 225 / B1 308——全段只有「背后负创而死」一个强词面，却被大段克制对白稀释。
  2. **低词汇强度、高回收的昔涟诞生**：`3.7|魔女|21`（K26/K27）A 273 → B1 26，是 B 相对 A 最大的提升；这段没有死亡词，力量来自「讲述者＝听众」「收梢＝起始」的结构回收（呼应 v2 §三.1 的反例）。
  3. **9 个双漏场景**（A/B1 都 >100）：K03、K28、K24、K19、K23、K05、K04、K16、K02——全部是长段告别/独白/群像诗，词面与结构特征都无处落脚（见 `knife-scenes-analysis.md` §5）。
  4. **关键事件表**：30 个关键节点中只有 22 个与神谕相关、8 个与神谕无关（E01 格奈乌斯之死、E03 万敌王朝终结、E06 公民大会、E13 世界真相、E18 千年后归来、E23 三月七合一、E27 创世诗等）——**「刀子 ≠ 神谕兑现」**。
- **数据/表/图证据**：`data-tables.md` §2（74 条、等级 18/28/17/11）、§3（A 0.4005 / B1 0.5812 / B2 0.5408；显著样本 Top100 覆盖 A 7/28 → B1 13/28；长度偏差 ρ 0.438→0.683）、§7（Q3 类型表）、§8（Q4）+ **F1/F2/F5/F6**；
  `data/reports/knife-scenes-analysis.md` §1（场景级 Top100：A 37.1% / B1 71.4%；双漏 9/35）；
  `data/config/key-events.json`（29 条含义变化）。
- **写作要点**：① 本章是「方法与证据」章，但开头仍要用一个失败案例（万敌 308 名）引入；② 明确区分「A/B 是候选发现器，不是文学裁判」；③ Spearman/Top-k 只在本章后半出现，且不要排成主线；④ 把「B2 短步负结果」写成诚实的边界，不藏；⑤ 用 8 个「与神谕无关的关键事件」证明显著性≠预言兑现。
- **缺口**：**A2 独立双标注未做**（现在只有重复稳定性 90%/60%，需在正文注明「稳定性≠准确率」）；A3 结构化证据字段、A5 抽样复核未做；敏感性分析（排除 uncertain 样本）待补；长度偏差的解释需一句「B 的增益集中在 >30 句层」。

### 第 6 章 命定的闭环：3.7 的告别、明天见与「收梢即起始」（建议 1800–2200 字）

- **本章论点**：故事把「命定如何被写定/接管」的答案放回结尾：黄金裔们把曾经写死他们的预言，改写成自己留下的告别词与创世诗；「明天见」从母亲临终的安慰、从遐蝶口中的「善意谎言」，变成他们共同写下的预言；昔涟的「收梢」让终结成为起始，闭合语言循环。
- **剧情案例**：
  1. **告别现场**：`3.7|银辇啊，挽别那人间史诗|12`（K29）——刻律德菈「无我，即无世界」（`#25695`）、海瑟音「世事如沧海…纵情高歌」（`#25707`）、万敌「去杀死纷争，荣光必然降临」（`#25716`）、遐蝶「请分出些温柔」（`#25726`）、那刻夏「阿那克萨戈拉斯的最后定理」（`#25734`）、阿格莱雅「信任与无私是华服」（`#25746`）、风堇「多笑一笑」（`#25755`）、赛飞儿「命运抓不住你」（`#25766`）、缇宝「明天见」（`#25778`）、白厄「明天见，乘以一千」（`#25779`）。

### 第 7 章 结论与局限（建议 800–1200 字）

- **本章论点**：翁法罗斯的命定观 = 语言形式 + 引用行为 + 回收结构；这三点可以被 NLP 测量，但不能被「情绪检测」替代。
- **三点结论**：
  1. **命定由语言写成**：神谕体可测量（文言/情态/第二人称/抽象名词），引用靠拢、改写偏离。
  2. **命定由角色接管**：引用轨迹从旁白/他人转向本人认领与宣告（弱趋势，34 处小样本）；镜像对 O10/O11 把「谁替谁念神谕」变成叙事装置。
  3. **命定由回收改写**：3.7 的告别/明天见/收梢把 3.0–3.6 的母题重新点亮；「前文被重新解释」正是显著性的来源，而不是死亡词。
- **局限（必须写，且给数量级）**：神谕 13 条 / 34 处引用 / 74 条标注 / 36 个场景都是小样本；标注为 LLM 辅助、单人重复（稳定性 90%/60%，无 kappa）；检索 gold 与吟诵步重合（A1 未拆分前无法做真语义对比）；3.5 嵌套闪回使语料顺序≠故事时间；读者真实情绪/弹幕数据不存在，不做任何情绪宣称；原文本不公开（只发代码/配置/统计）。
- **写作要点**：结论**不要再出现新的数字**；只回收第 1 章的三问与中心论点；把「不能宣称什么」写成一段而不是列表，以示诚实。
