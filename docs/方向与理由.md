# 项目方向与理由

> 记录时间：2026-10-23 ｜ 状态：方向已定，尚未开始分析
> 这份文件回答两个问题：**这个课程项目做什么**、**为什么是它**。

## 一、一句话

**以「神谕（预言）」为核心对象，用 NLP 方法分析翁法罗斯主线里"命定"是怎么被写进语言、又怎么被人认领与改写的。**

不是"验证某个假设"，而是：从语料里把神谕这套东西抽出来，顺着它在剧情中的出场与兑现一路追下去，最后得出关于"命定与挣脱"的结论。

## 二、为什么是神谕（剧情理解层面）

读完 3.0–3.7 后，我认为这部作品的主题是：**一个被写定的轮回里，人如何认领命运、又如何改写它**。而"被写定"这件事，在文本里不是抽象的，它就是**一套有固定形式的预言文本**：

1. **形式极稳定**：十二黄金裔各有一句神谕，统一是「汝将……」的韵文句式。这种统一性让它天然是一个可检索、可对齐的集合。
2. **名字被加密在文本里**：BWiki 用注音（ruby）标出了"表面词"与"真实所指"——「汝」注「白厄」，「灰白的黎明」注「开拓者」。**解码表是原文本自带的，不是我们猜的**（已抽取 1,020 对，见 `data/corpus/ruby-pairs.jsonl`）。
3. **预言有完整的生命周期**：神谕原文出现 → 角色在途中反复引用/自述 → 结局场景里被宣告兑现。以白厄为例：3.4 神谕原文「汝将肩负骄阳，直至灰白的黎明显著」→ 白厄亲自念给开拓者 → 3.7「我看见。灰白的黎明。升起。」→ 开拓者「——昭告『灰白的黎明』」。
4. **作者留下了互文对**：海瑟音与刻律德菈的神谕是**语序互换的镜像**（「于天地境界之海完成征服，长眠于涛声中」/「长眠于涛声中，于天地境界之海完成征服」），旁白还点明「她们从未恐惧这预言，甚至还有几分期盼」。这说明预言在这部作品里不是"命令"，而是"被期待的命运"。
5. **兑现方式并不机械**：阿格莱雅的神谕是「汝将最后一次沐浴，在温热耀眼的黄金中」——她在黄金浴池里自我落幕，是字面兑现也是主动选择的仪式。这类"字面/反转/错位"的区别，是有分析价值的类型学。

## 三、为什么是神谕（NLP 技术层面）

这个对象恰好能串起 NLP 的几种核心能力，而且**每一步都有能核对的产出**：

| 分析环节 | 做什么 | 对应 NLP 技术 | 产出 |
|---|---|---|---|
| ① 神谕库与解码表 | 从 wikitext 抽十二神谕韵文 + 1,020 注音对，交叉出「隐喻→所指」表 | 结构化信息抽取（模板/规则 + 统计过滤） | 神谕表、解码表 |
| ② 预言-事件对齐 | 把 12 条神谕与它们的兑现场景配对（人工标 12 对） | 文本检索/语义匹配：BM25、句向量，人工标注作评测 | 匹配结果 + Recall@k |
| ③ 引用轨迹 | 追每条神谕在剧情里出现了几次、由谁引用（本人/他人/旁白/敌人） | 引述检测、话语分析、时序统计 | 预言传播时间轴 |
| ④ 语体对照 | 神谕韵文 vs 剧情白描 vs 角色自述，比句长/文言色彩/情态词/人称 | 文体计量（特征工程 + 分类/聚类 + 显著性） | 语体三维对比图 |
| ⑤ 兑现类型 | 判定预言是字面、反转还是错位兑现 | 小样本标注 + 规则归纳 | 兑现类型学（12 例） |
| ⑥ 综合结论 | 把上面串成"命定如何被编码、如何被认领" | — | 论文式结论 |

**技术上的好处**：
- 有真数据（26,332 条台词 + 1,020 注音对），不是玩具集；
- 有真评测（12 对人工标注 + 检索指标 + 语体特征显著性），比"跑个分类器报准确率"硬；
- 有真发现（解码表、镜像对、引用轨迹），结论翻原文就能核；
- 算力门槛低（特征 + 小模型为主，可选句向量/BERT 做对比）。

## 四、分析会往哪里走（叙述，不是假设）

我会按这个链条往下写：

1. 先把神谕抽出来、把注音解码表建起来——**命定在这部作品里是可读的文本对象**；
2. 再看神谕怎么被角色反复提起——发现从"被他人转述"到"角色自我认领"再到"结局亲手宣告"的轨迹；
3. 比较神谕语体与日常对白——神谕有一套自己的用词、句式和情态（「将/必/终」），而角色在引用它时会**向这套语体靠拢**；
4. 最后看兑现：字面、反转、错位三种方式——**预言不是机械实现，而是被人以不同方式认领后实现**；
5. 落点：翁法罗斯的"命定"是语言建构的，"挣脱"恰恰体现为角色对预言的引用方式改变。

这些结论都不是先有假设再去找证据，而是**从材料里一步步看出来**的。

## 五、原来提过、现在退居次要的东西

| 内容 | 处置 | 原因 |
|---|---|---|
| 角色语体分类（原 H1） | 作为 ④「语体对照」的一部分，用"角色自述是否靠拢神谕语体"替代单纯的分类准确率 | 单纯角色分类太像作业，且对主题贡献小 |
| 语言成长（原 H2） | 降为一个补充观察（迷迷→昔涟），只在讨论部分出现 | 有意思但和神谕主线不在一条线上 |
| 称呼层级网络（原 H3） | 作为 ③ 的辅助证据（角色宣告预言时如何称呼对方） | 称呼本身是另一条线，不展开成主项目 |
| 双轴投影 / WMD / Louvain | 不做 | 方法老、无 ground truth、非 NLP 或易自证 |

## 七、已知难点（先写在这里）

1. **12 条神谕太少**：对齐环节只能做小样本 + 定性结合，报告里要说明是探索性研究；可把"神谕的一次出现"扩展为"引用句"，样本量会大一些。
2. **注音对需要分类**：1,020 对里大部分是"神名→神职"（如 尼卡多利→纷争之泰坦），真正是隐喻解码的只是一部分，要先分型。
3. **兑现判定需要人工**：12 条要逐条判定字面/反转/错位，必须给出判定标准与例子。
4. **语体差异可能被内容掩盖**：神谕谈抽象概念、对白谈具体事件，要控制话题影响（比如都用"关于命运"的句子对比）。
