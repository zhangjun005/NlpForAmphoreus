# 04 · 角色称呼集合：从 38 到 124 个规范名的两轮扩表

## 1. 目标与意图

语料里 `speaker` 是 **BWiki 页面原样的说话人标签**，同一角色会出现多种写法：

- 常用名 / 真名 / 外文名：`赛飞儿` / `赛法利娅`；
- 称号 / 爵位：`「冬霖爵」塞涅卡`、`「吟风爵」维吉妮娅`；
- 形态 / 分身：`迷迷`、`长夜月`、`缇安`、`缇宁`、`丹枫`；
- 复合标签：`「赛白厄」`（赛飞儿冒充白厄）、`永夜之帷，三月七`、`开拓者&昔涟`；
- 非角色标签：`？？？`、`旁白`、`【旁白】`。

如果不做归一，「谁说的话」会被拆成 505 个碎片，后续所有按角色的分析（情感轨迹、称呼网络、修辞指纹）
都会失准。因此本阶段目标是：**建一套可人工维护、可脚本执行、可审计的角色称呼配置**，
把 `speaker` 归一到 `canonical_speaker`（规范角色）+ `form`（形态/称号形态）两层。

## 2. 方案：需要哪些字段、从哪些渠道拿

### 2.1 数据模型（两层 + 负向过滤）

| 层 | 字段 | 说明 |
|---|---|---|
| 规范层 | `canonical_speaker` | 规范角色名（如 昔涟 / 白厄 / 开拓者） |
| 形态层 | `form` | 形态/称号/分身（如 迷迷 / 长夜月 / 缇安 / 永夜之帷） |
| 负向 | `meme_terms` | 梗名/网名/奇美拉名，**不参与说话人归一** |
| 非说话人 | `non_speaker_labels` | `？？？`、`旁白`、`系统`… 一律 `canonical=null` |
| 独立用途 | `address_scan_index` | 「称呼 → 被称呼者」反查，供**称呼网络分析**，不参与 speaker 归一 |

### 2.2 渠道选择（详见 `01-source-research.md` §2.2）

| 渠道 | 提供什么 | 局限 |
|---|---|---|
| BWiki 角色页（31 页，`fetch-nicknames.js`） | 称号/全名/外文名/`昵称/外号` | **只覆盖进卡池角色**；NPC 无页 |
| BWiki 设定页 `翁法罗斯` | 十二黄金裔、`X爵` 体系、前世黄金裔、迷迷定义 | 需按 `section=` 取节 |
| BWiki `模板:开拓者外号` | 主角命途形态外号 | 只有主角 |
| BWiki SMW | `称号/全名/外文名` 批量查询 | 结构简单，需人工复核 |
| 百度百科 | 无角色页 NPC 的别名（如帕姆）、黄金裔对照表 | 与 wiki 有少量出入 |
| 萌娘百科 | 别号、角色经历 | **API 被禁**，只能整页抓 |
| 语料本身（`amphoreus.lines.txt`） | 实证「实际出现的写法 + 句数」 | 只给证据，不给解释 |

## 3. 实施

### 3.1 称呼调研（`docs/speaker-aliases.md`，称呼集合 v4）

按角色族群人工整理，产出六大部分：

1. **主角（开拓者）**：本名「星（女）/穹（男）」；真实身份「阿基维利」；剧情称号「天外的旅者 → 创世的著者」；
   命途形态外号（毁灭=物主、存护=火主、同谐=虚数主/同谐主、记忆=冰主/记忆主）；
   各角色对主角的称呼（伙伴/搭档/救世主/异乡人/小灰/小家伙…）。
2. **三月七 / 丹恒**：多角色页（存护/巡猎/长夜月；丹恒/饮月/腾荒），前世丹枫。
3. **黄金裔 12 人**：每人给「常用名 / 真名 / 神权·火种 / 称号 / 昵称外号（含使用者）」，
   如 阿格莱雅=Aglaea+浪漫·墨涅塔+黄金的织者，缇宝=缇里西庇俄丝+门径·雅努斯+命运的三子。
4. **`X爵` 爵位体系（10 个）**：金织爵（阿格莱雅）、命运爵（缇宝）、捷足爵（赛飞儿）、摇光爵（风堇）、
   剑旗爵（海瑟音）、断锋爵（拉比努斯）、冬霖爵（塞涅卡）、吟风爵（维吉妮娅）、曳石爵（阿波罗尼）、钢甲爵（卢基塔克）。
   语料里常见完整署名格式 `「X爵」+本名`，必须剥前缀。
5. **前世黄金裔 = 当前十二泰坦**：玻吕茜亚（死亡）、卡吕普索（理性）、格奈乌斯（纷争）、卡厄斯（负世）；
   ⚠️ **`卡厄斯`（前世黄金裔）≠ `卡厄斯兰那`（白厄）**，不能合并。
6. **无角色页角色**：帕姆（百度百科补）、荒笛（BWiki 无页，设定页+百度百科）、来古士（全名吕枯耳戈斯）、
   塞涅卡、缇安/缇宁（重定向到缇宝）、长夜月（有页无昵称）。

另有一条**可量化观察线**：昔涟的官方演化线（BWiki 设定页原文「在逐火之旅中逐渐完善其语言能力，
最终变为昔涟的形象」）：德谬歌 → 迷迷 → 昔涟 → PhiLia093/「往昔的涟漪」→ 无瑕的真我。
为后续「迷迷台词长度/完整句占比随剧情是否单调上升」的分析预留了 `form` 维度（该分析尚未做）。

### 3.2 配置 v1（`data/config/speaker-alias.json`，实测 25,889 B）

**12 个顶层键**（数据字段的权威说明在 `docs/handoff.md` §4；`data/README.md` 只列了 9 个，漏了实现必需的 3 个）：

| 键 | 内容（v1） |
|---|---|
| `meta` | 版本、范围、来源、使用说明 |
| `normalization_order` | 6 条归一优先级 |
| `non_speaker_labels` | 8 个非说话人标签 |
| `title_prefix_patterns` | 3 条剥前缀正则（`「X爵」`/`「…」`/`『…』`） |
| `canonical` | **38 个角色**（protagonist 1 / playable 9 / golden_heir 12 / npc 15 / antagonist 1） |
| `form_map` | 32 条形态→角色（迷迷→昔涟、缇安/缇宁→缇宝、丹枫→丹恒…） |
| `speaker_literal_map` | 25 条「speaker 原文 → canonical+form」 |
| `address_scan_index` | 42 条称呼反查（救世主→开拓者、小白→白厄…） |
| `titan_canonical` | 13 泰坦（称号 + 对应黄金裔） |
| `meme_terms` | 41 个梗名/奇美拉名/网名（负向过滤） |
| `known_conflicts` | 6 条合并冲突裁决 |
| `pending_manual_review` | 待人工确认项 |

**归一优先级**（严格从高到低，禁止跳步猜测）：
`speaker_literal_map` 精确 → `canonical.speaker_aliases` 精确 → 剥 `「X爵」` 等前缀后重试 →
剥成对 `「」『』`/去括号注音后重试 → `form_map` → 仍未命中则 `null`。

`known_conflicts` 六条硬规则：卡厄斯≠卡厄斯兰那、铁墓≠白厄、长夜月→三月七、缇安/缇宁→缇宝、迷迷→昔涟、黑塔人偶/大黑塔→黑塔。

### 3.3 第一轮扩表：v1 → v2（38 → 124 个 canonical）

针对 `data/reports/unmatched-speakers.md` 的 **434 个未归一标签 / 4,043 条记录**逐项补配置：

|---|---|---|---|

| `form_map` | 32 | 47 | — |
| `speaker_literal_map` | 25 | 128 | — |
| `pattern_rules` | 0 | **17**（`X之声`/`X的投影`/`记忆中的X`/`X的记忆`/`先王X`/`元老X`/`「X爵」X`…） | — |
| `composite_rules.observed` | 0 | 21 实例（46 条记录） | — |

新增命中按类型（合计 **3,886 条**）：npc 1,423 / generic_npc 1,087 / golden_heir 563 / cameo 332 /
titan 297 / system 103 / playable 73 / protagonist 8。
其中泰坦 297 条 = 瑟希斯 157 + 欧洛尼斯 68 + 塞纳托斯 53 + 雅努斯 11 + 法吉娜 5 + 尼卡多利 3。

**效果**：v1 语料（23,090 条非空 speaker）上，命中率 **82.54% → 99.37%（22,944 条）**；
真正无法判定只剩 **9 条 / 3 个标签**（先祖之灵 4、`「闭嘴」` 4、古怪的弈者 1）。
配置 v2 实测 113,499 B，变更说明见 `docs/speaker-alias-changes.md`。

### 3.4 第二轮扩表：v2 → v3（外部复核勘误）

外部模型（Gemini）对 v2 配置与 5 份文档做交叉比对，指出 5 类勘误 + 4 个架构拍板 + 9 条未归一处置。
逐条采纳情况见 `docs/speaker-alias-errata.md`，配置 v3 实测 117,332 B：

| 类别 | 改动 |
|---|---|
| A 关系反转 | 「老日」是**开拓者叫星期日**，v2 写成星期日叫开拓者 → 修正 `called_by` 与 `address_scan_index` |
| B 越界版本 | 主角外号「欢愉主/雷主」属 4.2 版本，超出 3.0–3.7 → 从 `form_titles_by_path` 移除「欢愉」 |
| C 梗名污染 | `粉色芭芭拉`、`盾丹`、`炖蛋`、`冷面小粉龙`、`纠缠之缘`、`狗粮大队长`、`养母` 从 aliases 移入 `meme_terms` |
| D 误杀正式爵位 | `剑旗爵`（海瑟音正式爵位）从 `meme_terms` 移回 → 与金织爵/命运爵同级 |
| E 多义称呼 | `救世主`/`伙伴`/`心中的英雄` 从单指改为多义列表（扫描时需结合上下文） |
| F 置信度 | medium 推断升级为 confirmed（并给每条映射留 `review_note` 依据） |
| G 架构拍板（4 项） | 萨姆→流萤+form；四面镜**不拆**（canonical=面镜 + form=第N面镜）；泰坦之声留 generic_npc；刻法勒沿用 v1 判定→卡厄斯 |
| H 未归一处置（9 条） | `「闭嘴」`(4)→`non_speaker_labels`；`先祖之灵`(4)→generic_npc；`古怪的弈者`(1)→来古士+form |

配置 v3 结构：canonical 仍 124、`speaker_literal_map` 128→**135**、`non_speaker_labels` 15→**16**。
在 v3.1 新语料（24,041 条非空 speaker）上，归一命中 **23,460 = 97.58%**；
命中率低于 v2 的 99.37% 投影，是因为 v3.1 新增记录带来了 5 百多条**未登记的复合/新标签**（不猜，保留 null）。

## 5. 决策与取舍

| 决策 | 取舍 | 理由 |
|---|---|---|
| 用「canonical + form」两层模型 | 放弃「一角色一字符串」 | 迷迷/长夜月这类形态在剧情上有独立意义，压平会丢信息 |
| 泰坦**单列** canonical | 放弃「泰坦归到对应黄金裔」 | 泰坦≠黄金裔是设定硬规则；只有 `德谬歌→昔涟`、`刻法勒→卡厄斯` 例外 |
| `generic_npc` 聚合 | 放弃「每个路人一个条目」 | 长尾 247 个描述性标签无法逐个确认；但要求下游保留 `speaker_raw` |
| 梗名全部排除 | 放弃「用梗名做别名」 | 梗名是网友戏称，不是角色指代；放进别名会污染称呼统计 |
| 猜测性映射标置信度 | 放弃「一律视为确定」 | `medium` 映射（如「空白的愿望」→白厄）必须可审计、可回滚 |
| 未命中一律 `null` 不猜 | 放弃「尽量全覆盖」 | 宁可少覆盖，不可错并；错并会污染所有角色级统计 |
| `address_scan_index` 与 speaker 归一分离 | 放弃「一套表两用」 | 「谁在叫谁」与「谁在说」是不同任务，混用会互相污染 |

## 6. 踩过的坑与修正

1. **BWiki 角色页只覆盖卡池角色**：35 个硬编码页名抓取，`nicknames.txt` 实测为
   **31 个角色页段 + 3 个 `NO_NICK_FIELD` + 1 个 `MISSING`**（旧文档概括为「31 命中 + 4 MISSING」，
   实际是帕姆/来古士/塞涅卡无昵称字段、荒笛页面不存在），
   NPC（帕姆、塞涅卡…）完全没有可用的角色页。修正：转用设定页 + 百度百科 + 语料实证补齐；
   荒笛甚至 BWiki 无页，只能靠设定页与百度百科（记为「无角色页」单独处理）。
2. **昵称字段里混着「谁在叫」**：`昵称/外号` 常带 `〔注：使用者〕` 与 `{{黑幕|…}}`。
   如果整串塞进 `speaker_aliases`，会把「别人对他的称呼」当成「他的自称」。
   修正：拆成 `speaker_aliases`（他可能出现的说话人写法）与 `called_by`（谁怎么叫他）两套，
   后者只喂 `address_scan_index`。
3. **配置键被文档漏写**：`data/README.md` 只列 9 个顶层键，实际是 12 个——
   归一必需的 `normalization_order`、`non_speaker_labels`、`title_prefix_patterns` 没写。
   修正：在 `handoff.md` §4 补齐并注明「README 只列了 9 个」。
4. **梗名混入 aliases（外部复核 C）**：`粉色芭芭拉`（原神对比梗）、`盾丹/炖蛋`（玩家黑话）、
   `冷面小粉龙/纠缠之缘`（配色梗）、`狗粮大队长/养母`（社区梗）都来自 `{{黑幕}}`，被当成别名登记了。
   修正：全部移入 `meme_terms`，台词扫描默认忽略。
5. **正式爵位被当成梗名杀掉（外部复核 D）**：`剑旗爵` 是海瑟音的正式爵位，与金织爵/命运爵同级，
   却被放进了 `meme_terms` → 归一被错误拦截。修正：移回并补进 aliases。
6. **关系方向写反（外部复核 A）**：`星期日 … 老日〔注：开拓者〕` 原意是「开拓者叫星期日为老日」，
   v2 写成了「星期日叫开拓者老日」。修正：`called_by` 与 `address_scan_index` 双向纠正。
7. **越界版本外号（外部复核 B）**：`欢愉主/雷主` 是 4.2 版本内容，3.0–3.7 语料不会出现，
   留在配置里会给报告造成「跨版本」误导。修正：从 `form_titles_by_path` 移除「欢愉」。
8. **单指映射的风险（外部复核 E）**：`救世主` 在 3.0–3.3 主要指白厄、3.4 后才转向开拓者；
   `伙伴` 是白厄与昔涟互称。若固定单指，称呼网络会错。修正：改多义列表，并注明需上下文消歧。
9. **`form` 取值口径不统一**：v1 里「海瑟音」的形态写「记忆/幻象形态」，同类「记忆中的X」写「记忆形态」。
   修正：v3 统一为枚举值（`幻象`、`记忆形态`、`称号形态`…）；全量 form 从 v1 的 2,607 条/24 值
   扩到 v2 投影 3,965 条/60 值，final 实测 82 个非空 form 值。
10. **命中到「未登记角色」**：`「墨涅塔的幻影」` 经 literal 归到 `墨涅塔`，但 `canonical` 里没有墨涅塔。
    修正：v2 补登出 13 个泰坦 canonical，彻底修掉这类悬空引用。
11. **规模扩太快会失控**：v2 一次补 86 个 canonical 条目、247 个 generic 标签，
    最大风险是错并。修正：每条推断映射都带 `confidence` 与 `review_note`，并保留 `pending_manual_review` 清单。
