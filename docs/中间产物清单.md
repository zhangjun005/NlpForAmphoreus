# 中间产物清单（可复用语义资产）

> 目的：后续「含义变化」分析（神谕意义履历、概念阶段图、双层图）需要**向量空间与相似度矩阵**，这些不能每次重算。
> 生成脚本：`tools/export_artifacts.py`；输出目录：`data/models/`（**本地，已加入 .gitignore**，约 30 MB；不改原始语料，只存派生向量与 id）。
> 最近一次生成：见 `data/models/manifest.json` 的 `generated_at`（含 sha256/大小/shape）。

## 一、空间定义

| 空间 | 样本 | 特征 | 说明 |
|---|---|---|---|
| `seg_word` | 686 个步骤实例 | 20,389 | jieba 分词 TF-IDF；停用词 + 单字过滤（保留「汝/吾/花/海/火/光/梦」等）；`min_df=1`、sublinear |
| `seg_char` | 686 | 99,503 | 字符 2–3 gram TF-IDF，`min_df=2` |
| `rec_word` | 26,332 条记录 | 11,737 | 记录级 jieba TF-IDF，`min_df=2` |
| LSA | — | 100 维 | `TruncatedSVD(n_components=100, random_state=42)`，分别对 seg_word / rec_word |

> 注意：`TfidfVectorizer(analyzer=可调用分词器)` 时 sklearn 会忽略 `ngram_range`，所以词空间实际是**一元词**（文档已注明，避免误以为有 bigram）。字符空间是真正的 2–3 gram。

## 二、文件表（`data/models/`）

| 文件 | shape / 内容 | 用途 |
|---|---|---|
| `vec_word.joblib` | 向量器 | 把任意新文本映射进 seg_word 空间 |
| `vec_char.joblib` | 向量器 | 字符空间映射 |
| `vec_rec.joblib` | 向量器 | 记录级空间映射 |
| `X_word.npz` | 686 × 20,389 稀疏 | 段级 TF-IDF 矩阵 |
| `X_char.npz` | 686 × 99,503 稀疏 | 段级字符矩阵 |
| `svd_seg.joblib` / `Z_seg.npy` | 100 维 / 686 × 100 f32 | 段级 LSA 语义向量（用于聚类、阶段图、近邻） |
| `svd_rec.joblib` / `Z_rec.npy` | 100 维 / 26,332 × 100 f32 | 记录级 LSA 向量（含义曲线的细粒度锚点） |
| `S_seg.npy` | 686 × 686 f32 | 段间余弦相似度（GPT 第 4 步：全步骤相似度矩阵） |
| `S_oracle_seg.npy` | 13 × 686 f32 | 每条神谕 → 全部步骤的相似度（双层图下半部分的数据） |
| `S_knife_seg.npy` | 35 × 686 f32 | 35 个刀子场景 → 全部步骤相似度（找"最像的早前剧情"） |
| `S_anchor_seg.npy` | 14 × 686 f32 | 概念锚点（英雄/救世主/记忆/明天/毁灭/花/海/黎明/讲述者/听众/预言/神谕/命运/牺牲）→ 步骤相似度（概念阶段图） |
| `S_oracle_rec.npy` | 13 × 26,332 f32 | 神谕 → 记录级相似度（意义履历逐条定位） |
| `ids.json` | 对齐表 | `segments`（686 段 id）、`records`（26,332 记录 id）、`oracles`（13）、`knife_scenes`（35）、`anchors`（14）等，**所有矩阵行列顺序都以此为准** |
| `tokens_segments.json` | 686 条 token 列表 | 固定分词结果，避免 jieba 版本差异导致复现漂移 |
| `vocab_word.json` / `vocab_rec.json` | token→index | 查词、构造查询向量 |
| `feat_A.npy` / `feat_B.npy` | 686×10 / 686×30 f32 | 基线 A / B1 的原始特征矩阵（从结论 JSON 导出），供后续建模对照 |
| `feat_A.json` / `feat_B.json` | 特征名 + id 顺序 | 同上 |
| **`Z_sbert_seg.npy`** | **686 × 512 f32** | **中文句向量**（BAAI/bge-small-zh-v1.5，CPU；句子级语义空间） |
| **`S_sbert_seg.npy`** | **686 × 686 f32** | 句向量步骤间余弦相似度（与 `S_seg.npy` 的 TF-IDF 版对照） |
| **`S_sbert_oracle_seg.npy`** | 13 × 686 | 神谕句向量→步骤相似度（双层图的"语义相似"通道） |
| **`S_sbert_anchor_seg.npy`** | 14 × 686 | 概念锚点句向量→步骤相似度（概念阶段图） |
| **`Z_sbert_rec.npy`** | **26,332 × 512 f32（51 MB）** | 记录级句向量（意义履历逐条定位） |
| `manifest_sbert.json` | — | 句向量产物清单（模型名/维度/sha256/shape） |
| `manifest.json` | 清单 | 每个文件大小 / sha256 / shape / 生成参数 |

## 三、加载示例

```python
import json, numpy as np, joblib
M = "data/models/"
ids = json.load(open(M + "ids.json"))
S_seg = np.load(M + "S_seg.npy")          # 686×686
S_oracle = np.load(M + "S_oracle_seg.npy")  # 13×686
vec = joblib.load(M + "vec_word.joblib")

# 找 O09 最相关的 10 个步骤
oi = ids["oracles"].index("O09")
top = np.argsort(-S_oracle[oi])[:10]
print([ids["segments"][i] for i in top])

# 任意新文本映射进同一空间
v = vec.transform(["汝将肩负骄阳，直至灰白的黎明显著"])
```

## 六、复现

```bash
conda run -n nlpLesson python tools/export_artifacts.py
```

- 无随机（SVD `random_state=42`），同输入同输出；
- 若语料更新（`segments.jsonl` / `amphoreus.final.jsonl` / `oracles.jsonl` / `knife-scenes.json`），需重跑本脚本，并同步更新 `ids.json` 的对齐；
- 合规：`data/models/` 只存向量、词表、id 与派生矩阵，不含原始剧情文本；仍不入公开仓库。
