# docs 目录指引

> 先看 `docs/产物总览.md`（通俗版：每个产物是什么、模型是不是每角色一个、数字怎么回原文）。

| 文件/目录 | 内容 |
|---|---|
| `产物总览.md` | **通俗版产物清单**（语料/配置/模型/图/笔记/报告，以及"模型只有一套"的澄清） |
| `交付物规格.md` | 图-数据配对规范、模型归档清单、最终核对清单 |
| `中间产物清单.md` | 早期中间产物登记（可复现命令） |
| `方向与理由v2.md` | 研究问题与方向（主计划） |
| `NLP思路.md` / `通俗思路.md` | 两条写作口径的思路稿 |
| `实验口径与评测方案.md` | 冻结的评测协议（含 §12 裁定记录） |
| `标注方法修订.md` | 标注口径修订说明 |
| `计划-标注修订与刀子剧情.md` | 标注+刀子剧情计划 |
| `method/` | 方法说明（语料工程、归一、标注、评测、报告写作） |
| `stages/` | 8 个阶段的工作/方案/意图记录 |
| `log/` | 每步实际行动日志（01–23） |
| `report/` | 报告素材：`outline-annotator.md`（7 章结构）、`data-tables.md`、`figure-captions.md`、`figures-index.md`、`oracle-similarity-curves.md`、`figures/` |
| `agents.md` | 可复用 teammate 登记与派活模板 |
