# 母题「明天见」的向量分析：分析逻辑（供前端转换参考）

> 术语对照：本文用「词频加权」指 TF-IDF（词面表示）、「语义向量」指 SBERT/bge 句向量（语义表示）。

> 与《昔涟》歌词分析同一套方法：把一段短文本当"查询"，和角色质心、神谕、全部台词比较。
> 数据：`data/config/motif-query-mingtianjian.json`、`data/config/motif-query-zaijianmian.json`（对照词）；脚本 `tools/motif_query_report.py`。
> 前端副本：`frontend/docs/14-明天见母题.md`。

## 1. 这一页想回答什么

> 「明天见」这三个字，在向量空间里**最接近谁、最接近哪条神谕、最接近哪些不带这三个字的台词**？和另一个道别词「再见面」相比有什么不同？

## 2. 分析步骤

1. **查询文本**：`明天见`（对照：`再见面`）；分别编码成词频加权（词频加权）与语义向量（句向量）；
2. **承载句统计**：找出语料里所有包含该短语的记录（23 条），按版本/说话人统计；
3. **与 14 个角色质心比较**：看这句话在语义上最像哪个角色的"整体语言"；
4. **与 13 条神谕比较**：看它最接近哪条命定；
5. **找最接近、但不含该短语的台词**：避免"自我匹配"，看母题的语义邻居是谁。

### 3.5 对照：换成「再见面」

- 承载句只有 **2 条**（3.4、3.7）；
- 角色质心最高是**开拓者 0.627 / 三月七 0.620**；
- 最接近的神谕是 **O04（遐蝶，0.445）**，不是 O09；
- 语义邻居（不含短语）相似度整体更高（~0.77）——因为"再见面"本身更像完整句子，且与"重逢/再会"的台词簇高度集中。

→ 两个道别词的"语言中心"不同：「明天见」是**缇宝的母题（说的多）+ 昔涟的语义邻居（想的多）**；「再见面」是**开拓者/三月七的道别**。

## 4. 能说明 / 不能说明

**能说明**：母题的"承载者"（谁说的多）与"语义中心"（语义上最像谁）可以分离，这正是文本细读要区分的东西；「明天见」在 3.7 的收束者是群体+白厄，而不是说得最多的缇宝。

**不能说明**：不能因为相似度低就说"这不重要"；不能因为最近邻是昔涟就说"这个母题属于昔涟"——短语相似度的绝对值在高语义基线附近（0.55–0.71）。
