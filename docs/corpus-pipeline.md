## 2. 说话人归一规则

严格按 `data/config/speaker-alias.json` 的 `normalization_order` 执行：

| 优先级 | 规则 | 实现 |
|---|---|---|
| 1 | `speaker_literal_map` 精确命中 | 直接取 `canonical` + `form`（form 可为描述性标签，如「记忆/幻象形态」） |
| 2 | `canonical.speaker_aliases` 精确命中 | 取该角色的 canonical；`form` 仅当命中串本身就是已登记形态（`forms`/`form_map`）时填写 |
| 3 | 按 `title_prefix_patterns` 剥前缀后重试 1–2 | 如 `「阳雷骑士」塞涅俄丝` → `塞涅俄丝` |
| 4 | 剥成对 `「」『』`、去尾部括号注音后重试 | 如 `「遐蝶」` → `遐蝶`、`「丹恒」` → `丹恒` |
| 5 | `form_map` 命中 | `canonical` + `form` = 该写法（如 `长夜月` → 三月七 + form=长夜月） |
| 6 | 仍未命中 | `canonical=null`，保留原 `speaker`，进人工确认清单（`pending_manual_review`） |

补充约定（实现细节，均为"不猜"原则的延伸）：

- **候选写法 × 优先级**：先对原始写法跑 1→2→5，再对"剥前缀/去引号/去括号"的写法跑同一顺序，即优先级高于写法宽容度。
- **canonical 键兜底（位于 form_map 之后）**：`「断锋爵」拉比努斯` 这类 NPC 在配置里只有 `titles`、没有 `speaker_aliases`，剥前缀后精确等于 canonical 键才归一，不做任何模式推断。`form_map` 在它之前生效，因此 `长夜月` 仍归 `三月七 + form=长夜月`（遵守 known_conflicts），不会落到 `canonical["长夜月"]` 这条查询用条目。
- **`non_speaker_labels`**（旁白/？？？/遥远的男声/留言石板/神性的回响…）一律 `canonical=null`。
- **`meme_terms`**（梗名/奇美拉名/网名）不参与归一，命中即 null。
- **known_conflicts 全部遵守**：卡厄斯=前世黄金裔（≠卡厄斯兰那/白厄）、铁墓≠白厄、长夜月→三月七、缇安/缇宁→缇宝、迷迷→昔涟、黑塔人偶/大黑塔→黑塔。本脚本不在此之外新增任何合并。
- **未命中不猜**：`canonical=null` 的条目 `speaker` 原文完整保留；未匹配清单见 §2.3 与 §5。
