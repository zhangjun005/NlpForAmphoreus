## 2. 配对数据与 meta 规范

`<图名>.csv`：列名即图上的轴/分组（如 `group,level,score` 或 `order,version,tfidf_own,sbert_own`），一行一个绘图单元。

`<图名>.meta.json` 固定字段：

```json
{
  "figure": "f1_level_scores.png",
  "title": "A 与 B1 在人工等级上的分数分布",
  "axes": {"x": "人工显著等级", "y": "检测器分数（z 化）"},
  "plot_data_csv": "data/plot_data/f1_level_scores.csv",
  "sources": ["data/config/annotation-labels.json", "data/config/baseline-a-scores.json"],
  "filters": "74 个人工标注样本；A/B 分数取 segment 级",
  "generator": "tools/make_figures.py",
  "run_command": "conda run -n nlpLesson python tools/make_figures.py",
  "data_sha256_16": "…",
  "created_at": "…"
}
```

**换样式流程**：只改绘图脚本/样式 → 用同一份 `plot_data` 重画 → 比对 `data_sha256_16` 确认数据未变。

## 3. 模型与向量资产（归档清单）

`data/models/`：

| 资产 | 用途 |
|---|---|
| `vec_word.joblib` / `vec_rec.joblib` / `vec_char.joblib` | TF-IDF 向量器：**任意新文本**（含歌词）映射进同一空间 |
| `X_word.npz` / `X_char.npz` | 步骤级矩阵 |

| `ids.json` | 全部矩阵的行列对齐（records/segments/oracles/anchors） |
| `manifest.json` / `manifest_sbert.json` | 每个文件的 shape/sha256/生成参数 |

## 4. 任意新文本（歌词）查询口径

`tools/encode_text.py`：输入文本文件 → 输出 TF-IDF 与 SBERT 两套向量 + 相似度查询结果（JSON + CSV）。
`tools/query_similarity.py`：把新文本对以下对象做 Top-k 检索：

1. 目标角色全部台词（记录级）→ 最像的台词与步骤；
2. 目标角色的神谕文本；
3. 13 条神谕全矩阵（看是否更像别人的命定）；
4. 14 条角色曲线（步骤级）→ 落在剧情的哪个位置。

**口径红线**（写进报告）：
- 歌词是**篇外语料**，分布与游戏台词不同；结论只能是"向量接近程度"，**不能说"歌词证明了角色含义"**；
- TF-IDF（词面）与 SBERT（语义）两套结果都给，不一致时以人工判读为准；
- 结果只作探索性分析，样本是"一首歌 vs 角色台词"。
