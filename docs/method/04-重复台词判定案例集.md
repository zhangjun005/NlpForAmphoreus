# 重复台词判定案例集

> 结论先行：**「重复」不是一个东西，至少 8 类**。其中大部分含信息，真噪声只有「分支转录」和「可重复交互」两类。
> 这份文档记录我如何逐类判定，以及我在此过程中**两次判断错误的更正**。

## 一、背景数字

- 判重键：`task + kind + speaker + text` 全同 → **1,120 条**被标 `is_duplicate`
- 若键去掉 `kind`（只看 task+speaker+text）→ **1,126 条 / 630 组**
- 其中 filler（省略号/括号旁白/拟声/≤4 字）：**247 组 / 630 条冗余**
- 跨任务重复（同 speaker+同 text 出现在 ≥2 个任务页）：104 组，其中跨版本 69 组
- 全语料 filler 规模：约 **2,142 条（8.1%）**

## 二、八类重复（含原文证据）

### ① 母题 / 题眼 —— 有信息，最有价值

**「逐火是不断失却的旅途」共 14 条，跨 6 个版本、6 个说话人**：

| 说话人 | 后半句（各自改写） |
|---|---|
| 缇宝(缇宁) | 在那一切当中，生命也微不足惜 |
| **刻律德菈（敌对者）** | 生命亦微不足惜 |
| 阿格莱雅 | **但你会失去的，远比生命更为沉重** |
| 昔涟 | **可就算一切随风逝去，也有一种感情会被留下来……** |
| 白厄/旁白/开拓者 | 引用原句 |

**判定依据**：前件一字不改、后件因人而异；连敌人都引用 → 这是"世界的共识"被不同人改写。
**价值**：可直接量化「固定句式（命定）＋个体改写（挣脱）」，是本项目最有据的一条分析线索。

### ② 角色信念线 —— 有信息

**「明天见」共 23 条，跨 8 个版本，缇宝 13 条**。弧线清晰：
- 3.1：莫忒丝对缇宝说「明天见，我亲爱的缇里西庇俄丝」；缇宝回「妈妈…明天见」
- 3.1：遐蝶说「那句*明天见*只是一个善意的谎言」→ 缇宝答「*明天见*…是世上最伟大的预言」
- 3.1 末：缇宝对缇安说「明天见」（缇安随后牺牲）；3.3 旁白：「明天见，缇安。」
- 3.6/3.7：群像复诵；3.7 白厄「**明天见，乘以一千**」（呼应缇宝的千身）
**判定依据**：与角色死亡/分身设定绑定，首尾呼应。

### ③ 结构标记 —— 有信息

**「时间开始流动…」7 条，全部在 3.4，说话人全是旁白**，且紧跟：
> 距离世界毁灭还有 33550336 次永劫回归 / 昔涟留下的仪式剑将白厄送回时间的起点……
**判定依据**：它是**轮回重启/时间跳跃的锚点**，可以直接用来切分时间线。

### ④ 翻译节点 —— 有信息（并且能结构化）

**「（泰坦的低语）」48 条，分布于 4 个任务**；其中 **30 条紧接着是通译者遐蝶的译文**。
上下文（id 2696–2704）：`？？？（无法辨识的声音）` → 丹恒「什么声音？」→ 遐蝶「那是…泰坦在说话」→ `泰坦之声：（泰坦的低语）` → 遐蝶译文「狡猾、粗鄙之人…」→ 开拓者「**没字幕你怎么看懂的？**」
**判定依据**：说话对象 + 通译者结构；可抽取 `translation_of` 关系。

### ⑤ 仪式 / 群体口号 —— 有信息

**「死刑」14 条，3.2 集中 8 条**；说话人分布：generic_npc 7、那刻夏 1、风堇 2、阿格莱雅 1。
语境（id 11341–11342）：
> 那刻夏：**我，卑劣可耻的渎神者，应受死刑制裁……**
> 那刻夏：**而包庇我、纵容我、协助我完成渎神罪行的元老院，应与我同罪！**
**判定依据**：那刻夏**主动自请死刑**（策略：把元老院拖下水）→ 民众跟喊「死刑！」（情绪/被煽动）→ 元老院慌乱。群众喊得越齐，反衬那刻夏越冷静决绝。
**价值**：重复频次本身就是修辞强度。

### ⑥ 沉默 / 停顿 —— 中性，需标记

`……`、`（保持沉默）`、`（……）`：全语料最常见的是 `……`（QA 统计 671 条）。
**判定依据**：叙事停顿，不承载词汇信息，但**承载节奏与情绪**；统计"发言量"时不应计入，做时序分析时应保留。

### ⑦ 分支转录 —— 真噪声（应去重）

同一句台词挂在多个 `{{剧情选项}}` 分支下，BWiki 每个分支都记一遍 → 75 组。
**判定依据**：同一 action 的多个选项分支，玩家只能走一条，重复是转录冗余。

### ⑧ 可重复交互 —— 真噪声（可去重）

例：「你见过达米亚诺斯吗？」(6)、反复触发的旁白「播下因果的涟漪——」(7)、系统日志「>>>错误进程：解析中……」(6+5)。
**判定依据**：玩家可反复触发/反复播报，不属于叙事进展。

## 三、判定流程（建议按这个顺序）

```
这条重复是不是 filler（省略号/括号/拟声/≤4字）？
  ├─ 是 → ⑥ 沉默停顿（标记，统计时排除）
  └─ 否 → 是否跨任务出现（同 speaker+同 text 在 ≥2 页）？
        ├─ 是 → 看是否题眼/口头禅/结构标记 → ①②③
        └─ 否 → 是否系统日志/可反复触发？
              ├─ 是 → ⑧
              └─ 否 → 是否在多个选项分支下？ → ⑦ 分支转录
                      └─ 否 → 逐条人工看（可能 ④⑤）
```

## 四、我的两次判断错误（记录在此以免重犯）

1. **「1,120 条重复 = 轮回的语言证据」** ❌
   错因：只看了统计数字，没读文本。真相：轮回写成**同构句式**（`第 N 次永劫回归…盗火行者迫近`），不是逐字重复。

2. **「非 filler 重复主要是噪声」** ❌
   错因：看到大量 `（泰坦的低语）`/`>>>……` 就一概而论。真相：真噪声只有 ⑦⑧，其余 ①–⑥ 都有功能。

## 五、当前状态（已实现）

- **字段已加入 `amphoreus.final.jsonl`**：`repeat_kind`（9 值）、`repeat_scope`（single/within_task/cross_task）、`repeat_count`。
- 实现位置：`tools/finalize-corpus.js` 的 `classifyRepeat()`；规则与本文八类一一对应（含少量人工词表）。
- 实测分布（26,332 条）：

| repeat_kind | 条数 | 含义 |
|---|---|---|
| none | 24,725 | 非重复 |
| pause | 926 | 沉默/停顿/语气词 |
| structure | 244 | 轮回/系统结构标记 |
| branch | 228 | 分支转录（应去重） |
| loop_interaction | 109 | 可重复交互（应去重） |
| translation | 49 | 泰坦低语→通译 |
| motif | 23 | 母题/题眼（逐火… / 不要回头…） |
| catchphrase | 21 | 角色口头禅（明天见 / 嘟…嘟嘟） |
| ritual | 7 | 仪式/群体口号（死刑！死刑！） |

- 使用建议：频次/风格统计排除 `pause`+`branch`+`loop_interaction`；母题分析筛 `motif`；时间线分析用 `structure` 作锚点。
- 已知局限：分类是**规则+词表**，不是人工逐条标注；`none` 里仍有少量漏分（例如只出现 1 次但明显是台词的重复变体）。报告里应说明"分类为启发式，用抽查准确率背书"。
