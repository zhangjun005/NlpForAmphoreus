# 注音（ruby）语料：1,020 对「显示文本 ↔ 注音」

## 一、这是什么

BWiki 的 dialogue 里用了大量 `{{注音|正文|注音}}` 模板：**正文是玩家在对话框里看到的大字，注音是标在上方/下方的小字**。在游戏里它的作用是"表面称呼"与"真实所指"的对照。

原文样例：

```wiki
汝将肩负骄阳，直至{{注音|灰白的黎明|开拓者}}显著
```

显示给玩家的是「**灰白的黎明**」，小字注音是「**开拓者**」——**预言里藏着的名字，被注音直接写出来了**。

## 四、三个用途（这是它的价值）

### 1. 预言解码（对应"神谕"方向）

神谕是韵文、故意写得晦涩，但注音把答案直接写在旁边：
- 「汝」→ **白厄**
- 「灰白的黎明」→ **开拓者**

于是可以自动生成一张「预言隐喻 → 真实所指」的表，再对照剧情看它在什么时候兑现。**有确定答案、可核验**，不用靠热力图"看图说话"。

### 2. 称呼替换（对应"称呼层级"方向）

63 次「开拓者」注音「伙伴」、14 次「开拓者」注音「搭档」——说明游戏在**显示层统一用正式名**，但**发音层保留了角色真实称呼**。这等于官方替我们标注了"谁用什么称呼"，对关系网络/敬语层级分析是硬证据。

### 3. 神名-神职对照

224 个唯一对里大部分是 `泰坦名 → "X之泰坦"`，可以自动构建 13 泰坦的「神名 / 神职 / 对应黄金裔」对照表。

## 五、注意事项（抽的时候踩过）

1. **方向不要搞反**：`{{注音|A|B}}` = 显示 A、注音 B。写文档/报告时要写清"显示/注音"两个位置。
2. **可能嵌套黑幕**：`{{注音|赛法利娅|{{黑幕|赛飞儿}}}}`（阿格莱雅叫赛飞儿真名）。抽取时要先展开内层模板，否则 gloss 会是 `{{黑幕|赛飞儿}}`。
3. **当前主语料没有保留它**：解析时 `{{注音}}` 被展开成显示文本（A），注音（B）丢失。要把注音用于分析，必须用 `ruby-pairs.jsonl` 或回 wt-cache 重新抽。
4. **不是所有注音都是称呼/预言**：也有纯读音补充（如「门扉时」注「黎明」），需要按用途分类，别一概而论。
