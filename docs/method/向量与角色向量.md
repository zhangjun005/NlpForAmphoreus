# 向量与"角色向量"：三层结构与用法

> 记录时间：2026-10-24 ｜ 对应产物：`data/models/Z_sbert_rec.npy`、`character_centroids.npz`、`tools/encode_text.py`、`docs/产物总览.md` §3

## 三层结构

| 层 | 是什么 | 粒度 | 在哪 |
|---|---|---|---|
| **1. 基础向量** | 每条台词/旁白一个向量（SBERT 512 维；另有一套 TF-IDF 词面向量） | **每条记录**（26,332 条） | `Z_sbert_rec.npy`、`X_word/X_char.npz`、`vec_rec.joblib` |
| **2. 角色向量（质心）** | 该角色全部台词向量取平均、再 L2 归一化 = **一个向量**；按版本分别平均得到"分版本角色向量" | 每个角色 1 个 + 每版本 1 个 | `character_centroids.npz`（124 个向量）、`character-centroids.json` |
| **3. 派生用法** | ① 整体相似度（vs 歌词/其他角色质心）② 逐条 Top-k（最像他哪几句话）③ 分版本/曲线（哪个阶段最像） | 由用途决定 | `tools/encode_text.py --char`、`oracle-similarity-curves.json` |

## 一句话

> **没有"每人训练一个模型"；有的是"每人一句句向量平均成一个角色向量"。**

## 三种用法与适用问题

1. **质心相似度**（`encode_text.py --char` 的 `centroid_similarity`）
   - 回答："这段新文本整体上像不像这个角色？"
   - 例：歌词 vs 白厄质心（SBERT 0.648 是昔涟质心那次查询的示例值；具体数字以实际运行输出为准）。
2. **逐条 Top-k**（`char_topk_sbert` / `char_topk_tfidf`）
   - 回答："最像他的哪几句台词、在哪个版本/步骤？"
3. **分版本质心 / 相似度曲线**
   - 回答："他的语言在哪个阶段最像某条神谕/某段文本？"
   - （曲线是"按步骤聚合台词向量再和神谕比"，不是质心；见 `oracle-similarity-curves.json`）

## 必须记住的局限

- **质心会丢分布**：一半台词像 A、一半像 B，平均后可能什么都不像；
- **质心不能当"含义"**：相似度高 ≠ 歌词在讲同一个故事，只能说明向量空间里接近；
- **TF-IDF 与 SBERT 要分开说**：前者是词面、后者是语义，两套结果不一致本身就是发现（L3 已多次出现，如 O10/O11 镜像对 TF-IDF 全等、SBERT 微差）；
- **跨角色比较只能作探索**：角色台词量与风格差异大，质心相似度的高低要结合逐条 Top-k 与原文判读。

## 复现

```bash
conda run -n nlpLesson python tools/export_character_centroids.py     # 重算角色向量
conda run -n nlpLesson python tools/encode_text.py --file lyrics.txt --char 白厄   # 歌词 vs 角色
```
