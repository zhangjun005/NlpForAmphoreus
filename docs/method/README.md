# method/ ——「从剧情原文到语料」人类可读版

> 这套文档是给**人**看的（写报告、答辩、交接用），按"我拿到原文后，一步一步怎么处理、为什么这么处理、证据是什么"来写。
> 给 AI/自动化读的流水账在 `docs/stages/`，两者互补：**要理解方法读这里，要复现细节读那里。**

## 12 步速查表

| # | 步骤 | 一句话做法 | 关键依据 | 产出 |
|---|---|---|---|---|
| 0 | 定范围 | 只做「开拓任务」主线 3.0–3.7 | 活动=整活番外、活动背景时间错位、支线无关黄金裔、散落文本时间线乱 | 67 页范围 |
| 1 | 选数据源 | BWiki MediaWiki API + SMW | 实测：hakush 无剧情、B站字幕需登录且有解说、Fandom/中文维基被本地 DNS 拦、萌娘 API 禁 | 渠道结论 |
| 2 | 任务索引 | SMW ask `[[分类:开拓任务]][[任务地区::翁法罗斯]]` + 章节卡片核对补漏 | 页面正文是 `{{#ask:}}` 渲染的，抓 HTML 的 `<p>/<tr>` 命中 0 | 75 页（有效 67） |
| 3 | 剧情顺序 | 用 `前置任务/后续任务` 建链（64 边）做拓扑排序，同层按 (版本,编号) | 链一致性违例 0；3.3 有两个 #07 靠链排对；3.4 分支页有 4 个起点 | `quest-order.json` |
| 4 | 正文获取 | `action=parse&prop=wikitext` 取原文并缓存 | wikitext 保留说话人、选项、注音、折叠结构；HTML 会丢 | `wt-cache/` |
| 5 | 模板展开 | `{{颜色|x\|Y}}`→Y、`{{注音|A\|B}}`→A、`{{黑幕|x}}`→x | 不展开会截断：10 条正文只剩 `{{颜色` | 干净行文本 |
| 6 | 行级解析 | 状态机逐行判：标题→步骤；`*角色：台词`→dialogue；`{{角色对话}}`→dialogue+scene；`{{剧情选项}}`→option+分支；`{{短信选项}}`→sms；`:`开头→narration；`{{折叠}}`→extra | 每类都有原文-结果对照（见 01 文档 §6） | v31 语料 26,332 条 |
| 7 | 说话人归一 | 配置驱动 6 级优先级，输出 `canonical_speaker` + `form` | 称呼来源调研 + 两轮外部复核；未命中一律 null 不猜 | 97.58% |
| 8 | 文本清洗 | 另写 `text_clean`：去 `*强调*`、`他/她`→开拓者、清模板残留；原文不动 | 保护可回溯性；`他/她` 117 处、`*` 342 对 | 纯度全 0 |
| 9 | 视图与去重 | `view=main/extra`；重复保留并标 `is_duplicate`/`dedup_group` | 折叠块是可选闲聊；分支转录会重复 | 1,120 条标记 |
| 10 | 质检 | 顺序/完整性/文本纯度/渲染比对/未归一清单 | 渲染比对暴露了折叠块差异；QA 报告推翻了我的旧数字 | 3 份报告 |
| 11 | 外部复核 | Gemini 两轮交叉比对 → 配置 v3（45 条修订） | 关系反转、越界版本、梗名污染、优先级穿透 | v3 配置 |
| 12 | 交付 | 26,332 条 / 566,798 字 / 8 版本 / 67 页 | 见 `data/README.md` §十 | final 语料 |

## 三个数字先记住

- **26,332 条**记录、**566,798 字**、**67 个任务页**、**8 个版本（3.0–3.7）**
- 说话人归一 **23,460 / 24,041 = 97.58%**（v1 语料口径用 v3 配置可达 100% 有效归一）
- 文本纯度：`{{` / `}}` / `他/她` / `*` / HTML 残留 **全部 0**

## 复现命令（最少三条）

```bash
node tools/build-corpus-v31.js    # wt-cache → amphoreus.v31.jsonl（离线）
node tools/patch-alias-v3.js      # 生成说话人配置 v3
node tools/finalize-corpus.js     # → amphoreus.final.jsonl + 两份报告
```
